# 쿠팡 제품 캡처 → 숏폼 홍보영상 → SNS 게시 파이프라인

온라인(쿠팡 등)에서 캡처한 제품 정보를 받아 힉스필드로 15~30초 세로형(9:16) 홍보영상을 만들고,
릴스·인스타그램·틱톡에 바로 올릴 수 있는 캡션·해시태그·쿠팡파트너스 링크 자리까지 한 번에 준비하는 워크플로우.

## 전체 흐름

```
캡처 정보 받기(수동 입력) → [제품 사진 있으면] 업로드 위젯 → 훅 기획(3안)
→ 힉스필드 영상 생성(9:16, 15~30초) → 플랫폼별 캡션/해시태그 + 쿠팡파트너스 링크 자리 + 고지 문구
→ 게시 안내(틱톡은 자동 게시 가능, 릴스/인스타는 수동 업로드 안내)
```

## 1. 캡처 정보 받기 — 수동 입력

사용자가 쿠팡 페이지를 캡처해서 텍스트로 붙여넣는 방식을 기본으로 한다. 아래 항목이 빠져 있으면 물어봐서 채운다:

- **제품명** (필수)
- **가격** (있으면 — 영상 자막/캡션에 "특가", "할인율" 등으로 활용 가능)
- **핵심 특징 2~4개** (필수 — 훅과 셀링포인트의 재료)
- **제품 사진**: 있으면 다음 단계에서 업로드 위젯으로 받는다. 없으면 특징 설명만으로 힉스필드 텍스트→이미지 생성부터 시작한다 (이 경우 라벨/실물 재현이 불가능하므로 사용자에게 미리 안내).
- **타깃/톤**: 명시가 없으면 "가성비·실사용 후기" 톤을 기본으로 한다.

URL만 붙여넣고 스크래핑을 요청하면: 이 스킬은 자동 스크래핑을 하지 않는다. 캡처 화면을 텍스트로 옮겨 붙여넣어 달라고 요청한다 (쇼핑몰이 스크래핑을 차단하는 경우가 많아 안정적이지 않기 때문).

## 2. 제품 사진이 있는 경우 — 반드시 업로드 위젯 사용

채팅에 붙여넣거나 첨부한 이미지는 힉스필드 원격 도구가 읽을 수 없다. `media_upload_widget`을 띄워 다시 올리게 한다 (마찰을 줄이려면 이유를 짧게 설명하고 "이번이 마지막"임을 안내). 반환된 `media_id`는 이후 모든 생성 호출에 재사용한다.

- 사용자가 "올렸다"는데 media_id가 안 넘어왔으면 `show_medias`로 최근 업로드를 타임스탬프로 찾는다.
- 생성이 "Something went wrong"으로 반복 실패하면 업로드가 깨졌을 수 있다 — `media_import_url`로 재등록해 403이면 깨진 것, 새 media_id가 살면 정상이다.

## 3. 훅 기획 — 짧은 영상은 첫 2~3초가 전부

15~30초 세로형 영상 기준으로 3가지 훅 후보를 먼저 텍스트로 제시하고 사용자가 하나를 고르게 한다 (또는 명시적으로 요청하면 바로 하나로 진행):

- **문제 제기형**: "이거 아직도 이렇게 쓰세요?" 식으로 불편함을 먼저 던지고 제품이 해결
- **가격/혜택형**: 가격·할인율을 초반 1초에 크게 노출
- **비포/애프터형**: 사용 전후 비교로 임팩트

각 훅에 대해: 훅(0~3초) → 특징 2~3개를 빠른 컷으로(3~20초) → CTA(마지막 3~5초, "지금 링크 확인하세요" 류)로 비트를 나눈다.

## 4. 힉스필드로 영상 생성

- 제품 사진이 있으면 `higgsfield-product-ad-pipeline` 스킬의 라벨 보존 규칙을 그대로 따른다: 프롬프트 맨 앞에 "라벨의 인쇄 문구·컬러·비율은 원본과 동일하게 유지"를 배치하고, 텍스트 금지 조항은 "기존 라벨은 유지하되 **새로운** 글자/로고/워터마크는 생성 금지"로 수정한다.
- 비율은 릴스/틱톡 기준 **9:16** 고정, 길이는 15~30초 사이에서 기획한 비트 합계로 맞춘다.
- 짧은 프로모 영상에 특화된 프리셋이 필요하면 먼저 `shorts_studio_list_presets`로 적합한 프리셋이 있는지 확인하고, 있으면 `shorts_studio_create`/`shorts_studio_create_preset`을 우선 고려한다. 없거나 제품 라벨 재현이 중요하면 `generate_video`(모델 `seedance_2_0`, `mode: "std"`, `resolution: "1080p"`)로 직접 생성한다.
- 생성 시작 후 모델/설정을 요약해 알리고, `jobs_wait`로 상태 확인 → 완료되면 `job_display`로 결과 표시 + 결과 URL 텍스트 제공. 힉스필드 CDN이 네트워크 정책상 막혀 파일을 직접 전달 못 할 수 있으니, 그 경우 "브라우저에서 링크 열어 우클릭 저장" 또는 위젯 다운로드 버튼을 안내한다.

## 5. 플랫폼별 캡션 · 해시태그 · 쿠팡파트너스 링크 자리

영상이 나오면 릴스 / 인스타그램 / 틱톡 3종 캡션을 각각 만든다. 플랫폼별 톤 차이:

- **릴스(페이스북)**: 조금 더 설명적, 3~4문장
- **인스타그램**: 감성적 훅 + 짧은 문장 + 이모지
- **틱톡**: 반말·구어체, 트렌디한 표현, 가장 짧고 임팩트 있게

세 캡션 모두 아래를 포함한다:

1. 훅 한 줄
2. 핵심 특징 2~3개 (짧게)
3. **구매 링크 자리**: `🔗 구매링크: [쿠팡파트너스 링크 삽입]` — 사용자가 나중에 실제 링크로 교체
4. **쿠팡파트너스 고지 문구 (필수, 그대로 사용)**:
   > 이 포스팅은 쿠팡파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

   이 문구는 쿠팡파트너스 이용 정책상 광고/제휴 표시 의무이므로 임의로 생략하지 않는다. 인스타그램/틱톡은 캡션 본문에, 필요시 첫 댓글에도 추가하도록 안내한다.
5. 해시태그 8~12개 (제품 카테고리 + 트렌드성 + `#쿠팡파트너스` `#쿠팡추천` 포함)

## 6. 게시 안내

- **틱톡**: 계정이 연결되어 있으면(`tiktok_accounts`로 확인, 없으면 `tiktok_connect` 안내) `tiktok_prepare_publish` → `tiktok_publish`로 바로 게시할 수 있다고 안내하고, 사용자가 원하면 진행한다.
- **인스타그램 릴스**: 힉스필드에 직접 게시 도구가 없으므로, 완성된 영상 파일과 캡션 텍스트를 전달하고 수동 업로드를 안내한다.

## 7. 나중에 링크 채우기

쿠팡파트너스 링크가 아직 없다는 사용자에게는, 나중에 쿠팡파트너스(partners.coupang.com) 가입 후 해당 제품 페이지에서 "파트너스 링크 생성"으로 만든 링크를, 위에서 만든 캡션의 `[쿠팡파트너스 링크 삽입]` 자리에 그대로 교체해 넣으면 된다고 짧게 안내한다.
