# mynotes — Obsidian 활용 가이드

이 저장소는 [Obsidian](https://obsidian.md) vault(노트 저장소)로 쓰기 위한 곳입니다.
Obsidian은 로컬 마크다운(.md) 파일로 노트를 관리하는 앱이라, 이 git 저장소 자체가 그대로 vault 폴더가 됩니다.

---

## 1. Obsidian이란?

- **로컬 우선(Local-first)**: 모든 노트는 그냥 `.md` 파일. 특정 서비스에 종속되지 않고, 파일이 곧 원본입니다.
- **양방향 링크(Backlink)**: `[[노트 제목]]`으로 노트끼리 연결하면, 연결된 노트 쪽에도 자동으로 "이 노트를 링크한 문서" 목록(백링크)이 생깁니다.
- **그래프 뷰**: 노트 간 링크 관계를 시각적으로 볼 수 있어서, 생각이 어떻게 연결되는지 한눈에 파악됩니다.
- **플러그인 생태계**: 코어 기능은 가볍고, 필요한 기능은 플러그인으로 추가하는 구조입니다.

## 2. 시작하기

1. [obsidian.md](https://obsidian.md)에서 앱 설치 (Windows/Mac/Linux/iOS/Android 모두 지원)
2. 실행 후 **"Open folder as vault"** 선택 → 이 저장소를 로컬에 clone한 폴더를 선택
   ```bash
   git clone <이 저장소 주소>
   ```
3. 이후 Obsidian 앱에서 여는 폴더 = 이 git 저장소 폴더

> 즉, "노트 작성은 Obsidian 앱으로, 버전 관리·백업·동기화는 git으로" 하는 조합입니다.

## 3. 기본 개념

| 개념 | 설명 |
|---|---|
| **Vault** | 노트들이 들어있는 폴더 전체 (= 이 저장소) |
| **Note** | 마크다운 파일 하나 = 노트 하나 |
| **Link** | `[[노트 제목]]` 형식으로 다른 노트를 연결 |
| **Backlink** | 어떤 노트를 참조하는 다른 노트들의 목록 (자동 생성) |
| **Tag** | `#태그이름` 형식으로 분류 |
| **Frontmatter** | 파일 맨 위 `---` 사이에 넣는 메타데이터 (날짜, 태그 등) |

예시 노트:

```markdown
---
tags: [독서, 아이디어]
created: 2026-08-04
---

# 오늘 읽은 책

[[Obsidian 활용 가이드]]에서 본 내용과 연결됨.

#인사이트
```

## 4. 이 저장소의 추천 폴더 구조 (PARA 방식)

노트가 늘어나면 분류가 필요합니다. 대표적으로 **PARA** 구조를 추천합니다.

```
mynotes/
├── 00-Inbox/       # 일단 아무 데나 빠르게 적어두는 곳 (미분류)
├── 01-Projects/    # 마감이 있는 진행 중인 일
├── 02-Areas/       # 계속 관리해야 하는 영역 (건강, 재정, 커리어 등)
├── 03-Resources/   # 참고 자료, 지식 정리
├── 04-Archive/     # 끝났거나 더 이상 안 보는 것들
└── README.md       # 이 가이드
```

- 정답은 아니며, 노트가 적을 땐 폴더 없이 태그만으로 시작해도 충분합니다.
- 나중에 폴더를 옮겨도 링크는 안 깨집니다(Obsidian이 자동으로 링크 경로를 갱신).

## 5. 꼭 알아두면 좋은 핵심 기능

- **빠른 전환 (Ctrl/Cmd+O)**: 노트 제목으로 즉시 이동
- **명령 팔레트 (Ctrl/Cmd+P)**: 모든 기능을 검색해서 실행
- **일일 노트(Daily Notes)**: 오늘 날짜로 된 노트를 자동 생성 — 일기, 할 일, 회의록에 유용
- **템플릿(Templates)**: 반복되는 노트 양식을 자동 삽입
- **그래프 뷰**: 좌측 사이드바에서 전체 노트의 연결망 확인

## 6. 추천 플러그인 (Settings → Community plugins)

| 플러그인 | 용도 |
|---|---|
| Dataview | 노트 메타데이터로 표/목록을 자동 생성 (DB처럼 활용) |
| Templater | 고급 템플릿 (날짜, 변수 자동 삽입) |
| Calendar | 일일 노트를 달력 UI로 탐색 |
| Excalidraw | 손그림/다이어그램을 노트 안에 |
| Git | Obsidian 안에서 바로 git commit/push (아래 참고) |

## 7. Git과 함께 쓰기 (버전 관리 & 동기화)

이 저장소는 git repo이므로, 노트 변경 이력을 그대로 git으로 관리할 수 있습니다.

- **수동으로**: 노트를 쓰고 나서 터미널에서
  ```bash
  git add .
  git commit -m "노트 업데이트"
  git push
  ```
- **자동으로**: Obsidian의 **Git 플러그인**(Community plugin, 이름: "Obsidian Git")을 설치하면 일정 주기로 자동 commit/push/pull이 가능합니다. 여러 기기에서 쓸 때 특히 유용합니다.
- 이미 `.gitignore`에 Obsidian의 로컬 전용 설정(테마 캐시, 워크스페이스 상태 등)은 제외해뒀습니다. 플러그인 설치 목록(`.obsidian/community-plugins.json`) 같은 건 원하면 직접 커밋해서 기기 간 동기화할 수 있습니다.

## 8. 시작할 때 팁

1. 완벽한 구조를 처음부터 만들려 하지 말고, **일단 Inbox에 던져넣고 나중에 정리**하세요.
2. 노트 제목은 검색되기 쉽게 명확하게 짓는 게 폴더 구조보다 중요합니다.
3. 링크를 의식적으로 자주 연결하세요 — Obsidian의 진짜 힘은 그래프가 커질 때 나옵니다.
4. 매일 조금씩 쓰는 습관 자체가 폴더 정리보다 훨씬 중요합니다.
