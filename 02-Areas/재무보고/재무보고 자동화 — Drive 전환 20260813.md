### 왜 이전 방식이 동작하지 않았나

예약 작업은 **항상 클라우드에서 새 세션으로 실행**되며, 이 세션에는 데스크톱 브리지가 붙지 않는다. 앱을 켜두는 것과 무관하다.

> Scheduled tasks can't be tied to a folder on your computer. They work with connectors and the files saved to your Claude account.
> — [Schedule recurring tasks in Claude Cowork](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)

지금까지 성공했던 건은 전부 **대화창에서 수동 실행**한 것이었다.

## 기술 함정 3가지

### 1. 예약 작업은 로컬 폴더에 접근할 수 없다

Drive 동기화로 우회. 「컴퓨터」 섹션도 커넥터가 정상 조회함(검증 완료).

### 2. 업무일지는 다단 표라 텍스트 추출이 뒤섞인다

`pdftotext` 로 판정하면 브랜드 귀속이 틀어진다. `pdftoppm -png -r 300` 으로 렌더링해 **이미지를 직접 보고** 판정한다. 프로젝트 업로드 방식은 텍스트만 넘어와 이 방법을 못 쓰므로 부적합.

### 3. 폰트 미임베딩 — 한글이 안 보인다

스킬 원본 `generate_report.py` 는 `UnicodeCIDFont` 사용 → `pdffonts` 에서 `emb=no`.
한글 폰트팩이 없는 뷰어(크롬·엣지 내장 등)에서 **글자가 통째로 사라진다.**

```bash
apt-get install -y fonts-nanum
pyftsubset /usr/share/fonts/truetype/nanum/NanumGothic.ttf --text-file=chars.txt \
  --output-file=one.ttf --layout-features='' --no-hinting \
  --drop-tables+=GSUB,GPOS,GDEF,DSIG,kern,hdmx,VDMX,LTSH,gasp
# gen.py: UnicodeCIDFont -> TTFont('one.ttf')
pdffonts final.pdf   # emb=yes 확인 필수
```

기존 재무보고 PDF는 대부분 이 결함을 갖고 있다. **3~15KB 크기가 신호.**
