# 황금정원 승인글 쓰는 방식 (2026-10-26 확정)

티스토리(diary21462.tistory.com) 애드센스 승인글은 아래 방식으로만 쓴다. 다른 세션·자동 루프도 이 문서를 따른다.

## 1. 재료 3가지가 있어야 쓴다
1. **유튜브 참고 영상 + 대본(스크립트)**: 글감을 고르면 Claude가 대본이 나오는 영상을 찾아 준다. 대본이 없으면 Claude가 근거 자료를 정리하고 출처를 밝힌다.
2. **내 경험 (500자 내외)**: 사용자가 직접 쓴다.
3. **내 생각/비판 (500자 내외)**: 사용자가 직접 쓴다.

- 경험은 사용자가 준 내용만 쓴다. **없는 경험을 지어내지 않는다.** 일반적인 예를 들 때는 "예를 들어"처럼 예시임을 밝힌다.
- 영상 속 사연·수치는 "영상에서 소개된 사연에 따르면"처럼 출처를 붙여 쓴다.

## 1-1. 참고 영상은 Claude가 찾아서 제시한다
- "글쓰자"라고 하면 Claude가 중복 없는 글감 3~5개를 고르고, **글감마다 한국어 유튜브 참고 영상을 찾아 함께 제시**한다.
- 고르는 기준: 한국어 영상, 대본(스크립트)이 나올 가능성이 높은 영상(5분 이상 강연·인터뷰·방송·전문가 채널, 쇼츠 제외), 가능하면 최근 3년 이내, 이미 쓴 글의 참고 영상과 겹치지 않을 것.
- 영상마다 링크·채널명·한 줄 요약을 주고, 글감을 고르면 주 영상 1개 + 대체 영상 1개를 준다.
- 대본이 안 나오면(사용자가 '스크립트 표시'를 확인) 대체 영상으로 바꾸거나, 영상 없이 Claude가 근거 자료를 정리하는 방식(A안)으로 진행한다.

## 2. 형식은 무작위
- 12개 형식(`.agents/loops/tools/layouts.json`, 스튜디오와 같은 목록) 중 **최근 3편 형식을 빼고** 무작위로 고른다. 어조·도입·소제목 구조도 무작위.
- 사용자는 형식을 고르지 않는다. 카드형으로 고정하지 않는다.

## 3. AI가 쓴 티가 나지 않게
- 사용자가 쓴 경험·생각의 표현과 말버릇을 최대한 살린다. 매끈하게 다듬어 일반론으로 만들지 않는다.
- 금지: "~에 대해 알아보겠습니다", "결론적으로", "다양한", "중요합니다" 남발, "흥미로운/주목할 만한", 이모지, 마크다운 기호.
- 문단 길이를 일부러 들쭉날쭉하게. 모든 소제목이 같은 길이·같은 3단 나열이 되지 않게.
- 추상적 문장 대신 구체적인 장면·숫자·행동(예: "회사에서는 10만 원짜리 비용도 증빙을 챙기면서")을 쓴다.
- 글 쓰는 장치를 설명하는 안내문("~를 옮겨봅니다"), 명언 같은 결론, "여러분은 어떠신가요?" 같은 상투적인 마무리 질문은 피한다.

## 4. 두 번 검토한 뒤 드린다 (Claude + ChatGPT)
1. **Claude 검토**: 스튜디오 자동 점검(분량·링크·목록·소제목·금지어) + 인용한 연구 링크를 직접 열어 사실 확인.
2. **ChatGPT 교차 검토**: `python3 .agents/loops/tools/gpt_review.py <post.json>` (OPENAI_API_KEY 필요, 기본 모델 gpt-5.5). AI 티 나는 문장, 애드센스 위험, 사실 확인, 지어낸 경험 여부를 점검한다.
3. 지적을 반영해 고친다. **점수 85점 미만이면 고친 뒤 다시 검토**한다.
4. 검토 결과(점수·고친 점)는 스튜디오 문서의 `review` 칸에 저장하고, 사용자에게 한 줄로 알려 준다.

## 5. 애드센스 기준
- 본문 2,000자 이상, 소제목 2개 이상, 목록 1회 이상.
- 근거 출처 2개 이상 + 맨 아래 참고 영상 링크. 연구는 원문 제목·학술지 영문명을 함께 적는다.
- 건강·돈 이야기는 단정하지 않는다. 필요하면 "제 경험이며 투자/의학적 권유가 아닙니다"를 넣는다.
- Pixabay 사진 1장, 쓰레드 문구(500자 이내), 첫 댓글 문구.

## 6. 발행
- 주 2~3회, 하루 1편 이하(월~일 기준). 한도를 채운 날은 미리 써 두고 티스토리 예약 발행.
- 쓰레드 첫 댓글은 발행 후 실제 `/entry/` 주소로 붙인다.
- 발행 후 스튜디오 완료 체크 → mynotes 기록은 보여 주고 확인받은 뒤 저장.

## 7. 자동 루프(월요일)의 역할
- 완성 글을 쓰지 않는다. **글감 카드**만 준비한다: 주제, 대본 있는 참고 영상 후보, 경험 떠올리기 질문, 비판 쟁점, 근거 자료 링크.
- 이미 루프가 써 둔 초안(아침형은 타고날까, 주말 늦잠의 함정)은 그대로 발행하지 않고 글감 자료로만 쓴다.
