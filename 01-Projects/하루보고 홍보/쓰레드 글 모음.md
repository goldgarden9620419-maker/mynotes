# 하루보고 — 쓰레드(Threads) 글 모음

> 운영 방침: 메이커 스토리(만드는 과정을 공개) + 실무 팁, 주 2~3회
> 발행 간격: 1~3일에 1편, 같은 날 여러 편 금지
> 글자 수: 편당 500자 이내 (쓰레드 제한)
> 발행 여부를 여기 체크로 기록

## 1편 — 소개 훅 (첫 글, 프로필 고정 추천)

- [x] ✅ 발행 완료 (9/5)

```
회사에서 재무 일을 하면서
매일 대표님 보고서 정리에 30분씩 썼습니다.

숫자는 이미 업무일지에 다 있는데
그걸 보고서 모양으로 옮기는 데만 30분.

너무 아까워서 직접 만들었어요.
파일 올리면 1분 만에 보고서로 바꿔주는 서비스.

이름은 '하루보고'입니다.
가입 없이도 파일 1개는 바로 체험돼요.

현직 재무담당자가 만들면서 배운 것들,
여기에 하나씩 기록해보려고요.

harubogo.vercel.app
```

## 2편 — 부장님 가격 피드백 스토리 (1편 발행 1~3일 뒤)

- [ ] 발행

```
베타 테스터인 부장님께 피드백을 받았는데
"월 29,000원은 좀 비싼 느낌인데?"

솔직히 처음엔 '가치를 몰라주시네' 싶었는데
다시 여쭤봤어요. "얼마면 쓰실 것 같으세요?"

"2만 원 정도?"

그날 바로 가격을 바꿨습니다.
사전 등록하면 월 19,900원, 계속 그 가격.

만드는 사람 생각보다
쓰는 사람 대답이 정답에 가깝더라고요.

가격 정하느라 고민 중인 분들,
고객한테 그냥 물어보세요. 공짜입니다.
```

## 3편 — 양식 나눔 (2편 발행 1~3일 뒤)

- [ ] 발행

```
경리·재무 하시는 분들께 무료로 드립니다.

10년 가까이 실무에서 다듬은
업무일지 엑셀 양식이랑 자금일보 양식.

계좌 잔액, 입출금, 매출, 특이사항, 내일 예정.
이 순서대로만 적어도
대표님 보고가 훨씬 편해져요.

가입 없이 그냥 받아가시면 됩니다.
harubogo.vercel.app/templates

(그리고 이 양식 그대로 올리면
보고서가 자동으로 만들어지는 것도
제가 만들었습니다... 궁금하면 눌러보세요)
```

## 이후 소재 아이디어 (토요일 루틴 글과 연동)

- 베타 피드백 당일 반영 스토리 (암호 엑셀 오류 → 그날 고침)
- 게스트 모드 만든 이유 (가입 장벽 데이터)
- 비개발자가 클로드로 SaaS 만드는 과정
- 매주 블로그 글 발행할 때마다 쓰레드 예고편 1개 (블로그 링크 연결)

## 운영 팁

- 1편은 프로필에 고정 (쓰레드 글 ··· 메뉴 → 프로필에 고정)
- 링크는 본문 끝에 1개만 (링크 도배는 노출에 불리)
- 댓글 달리면 꼭 답글 (초기엔 대화가 노출을 키움)
