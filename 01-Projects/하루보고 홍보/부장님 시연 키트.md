# 부장님 시연 키트 (5분)

> 목적: "이 사이트가 내 일을 알까?"라는 의문에 말이 아니라 화면으로 답하기.
> 준비물: 이 폴더의 **"영업부 업무일지 (시연용 가상).xlsx"** + 아래 양식·지침 텍스트 (전부 가상 데이터 — 실제 회사 자료 사용 금지)

---

## 시연 순서 (5분)

**0. 준비 (시연 전에 미리)** — jade 계정으로 로그인해두고, 아래 ①양식과 ②지침을 복사할 수 있게 이 노트를 열어두기 (또는 휴대폰에)

**1. 양식 붙여넣기 (1분)** — 새 보고서 화면에서 "📄 우리 회사 보고서 양식 펼치기" 클릭 → 아래 ① 붙여넣기
→ 멘트: *"부장님이 쓰시는 보고서 양식을 여기 붙여넣으면, 결과가 그 구성 그대로 나옵니다."*

**2. 지침 입력 (30초)** — "📝 정리·보고 방식 펼치기" 클릭 → 아래 ② 붙여넣기
→ 멘트: *"'나는 이런 걸 중요하게 본다'를 한 번 적어두면 매번 그 기준으로 정리해줍니다."*

**3. 파일 업로드 → 변환 (1분)** — "영업부 업무일지 (시연용 가상).xlsx" 업로드 → [자료 분석하고 보고서 만들기]
→ 기다리는 동안 멘트: *"이건 가상 샘플이고, 부장님 실제 일지로 하면 부장님 내용이 그대로 이렇게 됩니다."*

**4. 결과 확인 (2분)** — 나온 보고서에서 세 가지 짚기:
- **양식 그대로**: 섹션 순서·이름이 ①에서 붙여넣은 그대로인 것
- **지침 반영**: 매출이 채널별 표로, 클레임에 처리 완료 표시가 붙은 것
- **숫자 신뢰**: 업무일지의 8,030,000원·84건이 보고서에 그대로 — *"원문에 없는 숫자는 절대 만들지 않는 게 원칙입니다"*

**5. 마무리 (30초)** — *"부장님 양식과 기준을 한 번만 가르쳐주면 매일 이렇게 나옵니다. 정식 오픈 때 첫 달 할인 드리는 사전 등록만 눌러두시면 돼요."* (요금제 → 사전 등록 버튼)

---

## ① 붙여넣을 보고서 양식 (부장님 스타일 예시 — 실제 시연 땐 부장님 진짜 양식으로 교체 가능)

```
[영업부 일일 보고]
보고일:
1. 금일 매출 요약 (채널별)
2. 거래처 동향 및 미팅 결과
3. 발주·재고 현황
4. 클레임 및 처리 결과
5. 결재 요청 사항
6. 명일 계획
```

## ② 붙여넣을 정리·보고 지침

```
매출은 채널별 표로 정리하고 합계와 전일 대비를 함께 적는다. 클레임은 건별로 처리 완료 여부를 반드시 표시한다. 결재 요청 사항은 금액을 함께 적는다. 어려운 한자어 없이 짧은 문장으로.
```

---

## 주의

- 시연에는 **반드시 이 가상 샘플만** 사용 (실제 회사 데이터·실거래처명 화면에 띄우지 않기)
- 부장님이 "내 양식으로 해보자" 하시면 그 자리에서 ①만 부장님 양식으로 바꿔 다시 변환 — 이게 최고의 마무리
- 시연 후 반응(등록 여부·추가 의문)은 클로드에게 공유 → 9/28 토스 결정 재료
