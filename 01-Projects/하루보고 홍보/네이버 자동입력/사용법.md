# 네이버 블로그 반자동 입력 — 사용법

가장 최근 "블로그 글 N" 원고를 읽어서 네이버 글쓰기 화면에 **제목 → 본문 → 엑셀 첨부 → 태그 → 카테고리**까지 자동으로 채웁니다.
**마지막 "발행" 버튼만 직접 누르면 끝.** (계정 보호를 위해 자동 발행은 일부러 넣지 않았습니다.)

## 처음 한 번만 (약 5분)

1. 파이썬 설치: https://www.python.org/downloads/ → 노란 Download 버튼
   - 윈도우: 설치 첫 화면 아래 **"Add python.exe to PATH" 체크** 후 Install Now
   - 맥: 받은 파일 실행 → 계속 → 설치
2. 크롬 브라우저가 있는지 확인 (없으면 윈도우는 엣지로 자동 대체)
3. 맥만: "실행 (맥).command"를 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 → 파일 우클릭 → 열기 → 열기

## 바탕화면 바로가기 (한 번만)

- 이 폴더의 **"바탕화면 바로가기 만들기.bat"** 더블클릭 → 바탕화면에 **"네이버 블로그 발행 (하루보고)"** 아이콘 생성
- 다음부터는 Obsidian에서 Pull만 하고 **바탕화면 아이콘 더블클릭**하면 끝
- 폴더 위치를 옮기면 바로가기가 끊기니, 그때는 이 파일을 다시 한 번 더블클릭

## 매주 발행할 때

1. Obsidian에서 이 폴더(하루보고 홍보/네이버 자동입력)를 탐색기/Finder로 연다
   - Obsidian 왼쪽 파일 목록에서 폴더 우클릭 → "시스템 탐색기에서 보기"
2. **윈도우: "실행 (윈도우).bat" 더블클릭 / 맥: "실행 (맥).command" 더블클릭**
3. 처음 실행이면 크롬이 네이버 로그인 화면으로 열림 → 직접 로그인 ("로그인 상태 유지" 체크)
   - 다음 주부터는 로그인 없이 바로 글쓰기 화면이 열림
4. 자동 입력이 끝나면 검은 창에 "입력 완료!"가 뜸
5. 브라우저에서 내용 훑어보고 → 발행 창의 초록색 **"발행"** 클릭
6. 검은 창에 **y 입력 후 Enter** → 발행 완료로 기록되고 브라우저가 닫힘
   - 발행 안 하고 닫을 땐 그냥 Enter (브라우저 X 대신 이 방법으로 닫아야 다음에 '페이지 복원' 창이 안 뜸)
   - 이미 발행한 글은 다시 채우지 않고 "새로 발행할 글이 없습니다"라고 알려줌

## 이럴 땐

| 상황 | 해결 |
|---|---|
| 검은 창에 "일부 단계는 직접 해주셔야 합니다" | 적힌 단계만 손으로 하면 됨. 네이버 화면이 바뀐 경우라 "오류기록" 폴더의 캡처와 함께 알려주시면 고쳐드립니다 |
| 지난 글(예: 글 3)을 다시 넣고 싶을 때 | 검은 창(명령 프롬프트)에서 `py naver_post.py 3` |
| 원고만 제대로 읽히는지 확인 | `py naver_post.py --dry` (브라우저 안 열림) |
| "Python is not installed" | 위 1번 설치, 윈도우는 PATH 체크 필수 |
| 로그인이 계속 풀림 | 로그인 시 "로그인 상태 유지" 체크 |
