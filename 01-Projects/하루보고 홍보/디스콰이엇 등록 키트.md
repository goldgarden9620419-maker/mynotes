# 디스콰이엇 등록 키트 (10분)

> 디스콰이엇(disquiet.io) = 한국 메이커·스타트업 커뮤니티. 프로덕트를 등록하면 얼리어답터 유입 + 피드백을 받을 수 있음.
> 준비물: 아래 복붙 텍스트 + 스크린샷 2~3장 (랜딩, 브리핑 카드, 보고서 화면 — **가상 데이터 화면만!**) + 앱 아이콘(파란 보고서 아이콘, 사이트에서 우클릭 저장 가능: harubogo.vercel.app/icon-512.png)

## 등록 순서

1. disquiet.io 접속 → 회원가입 (구글 계정으로 간단)
2. 오른쪽 위 **[+ 프로덕트 만들기]** (또는 "프로덕트 등록") 클릭
3. 아래 내용 복붙 + 스크린샷 업로드 → 게시
4. 게시 후 "메이커로그"에 짧은 소개 글 하나 올리면 노출에 도움 (아래 ③ 사용)

---

## ① 기본 정보

- **프로덕트명**: 하루보고
- **한 줄 소개**: 업무일지·영수증을 올리면 대표님 보고서가 1분 만에 — 경리·재무 담당자의 매일 30분을 돌려드립니다
- **링크**: https://harubogo.vercel.app
- **카테고리/태그**: 생산성, B2B, SaaS, AI, 재무, 자동화

## ② 상세 소개 (복붙)

```
현직 중소기업 재무담당자가 자기 일을 자동화하려고 직접 만든 서비스입니다.

매일 아침 업무일지를 대표님 보고서로 옮겨 적는 데 30분씩 쓰다가, 이 과정을 통째로 자동화했습니다. 지금은 제가 매일 실무에서 쓰면서 다듬고 있어요.

■ 뭘 해주나요
- 업무일지·거래내역·영수증(PDF/엑셀/워드/한글hwp/CSV, 스캔본도)을 올리면 보고용 문서로 자동 변환
- 쓰시던 보고서 양식을 붙여넣으면 그 구성 그대로 재현 (회사마다 양식이 달라도 OK)
- "매출은 표로, 클레임은 처리 여부 표시" 같은 지침을 한 번 적으면 계속 그 기준으로 정리
- 원문에 없는 숫자는 절대 만들지 않고, 애매한 내용은 확인 표시로 따로 알려줌
- 매일 아침 경제·정치 브리핑 (지표 + 뉴스 + "나의 실생활엔 무슨 영향?" 요약)

■ 이런 것도 있어요
- 실무 엑셀 무료 양식 5종 (업무일지·자금일보·월말 결산·주간 자금계획·일정관리 간트차트) — 가입 없이 다운로드
- 홈 화면에 앱으로 설치 가능 (PWA)

■ 왜 만들었나
챗GPT로도 한 번은 됩니다. 그런데 매일 하는 보고는 "어제와 같은 모양"이 생명이라, 프롬프트 없이 올리면 끝나는 도구가 필요했어요. 재무 담당자가 매일 쓰는 도구라서, 숫자 정확성에 가장 공을 들였습니다.

가입 없이 파일 1개는 바로 체험할 수 있습니다. 경리·재무 실무자의 솔직한 피드백이 제일 고픕니다. 🙏
```

## ③ 메이커로그 첫 글 (복붙)

```
재무팀에서 일하며 매일 30분씩 보고서를 옮겨 적다가, 그 일을 자동화하는 서비스를 만들었습니다. 하루보고입니다.

코딩은 못 하지만 AI 도구로 두 달째 만들고 있고, 베타 사용자 20명, 네이버 검색 "자금일보 양식" 1위까지 왔습니다. 광고비는 0원, 무료 양식 나눔과 검색 유입으로만요.

실무자가 만드는 실무 도구가 어디까지 갈 수 있는지 기록해보겠습니다. 피드백 환영합니다.
```
