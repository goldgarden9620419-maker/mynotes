## 3. 겹침 방지 규칙 (매주 루틴이 점검)

1. **입력 파일 또는 결과물 중 하나는 반드시 기존 양식과 달라야** 한다. 둘 다 같으면 새 글 대신 "기존 양식 업데이트"로 처리한다.
2. **공략 키워드는 기존 글과 겹치면 안 된다.** 홍보 폴더의 모든 "블로그 글 N" 원고의 "공략 키워드" 줄과 대조한다.
3. **세법·노동법·4대보험 관련 내용은 매번 최신 출처를 검색해 날짜와 함께 확인**한다. 틀리면 피해가 큰 주제다. 확인 못 한 내용은 쓰지 않는다.
4. **양식 기본 규칙:** 붙여넣기 자동 처리(원본 파일을 그대로 붙여넣는 시트 + 자동 정리 시트), 매크로 없는 순수 수식, 첫 시트에 순서도형 사용법, 노란 칸만 입력, 눈금선 숨김, 예시 데이터는 전부 가상.
5. 발행 후 이 파일의 해당 줄을 **1번 표(완료)로 옮기고** 글 번호·키워드·사이트 파일명을 적는다.
6. **사용성 규칙 (2026-10-08 jade 지시: "사용자들이 불편함 없게")** — 모든 붙여넣기 양식에 적용
   1. **설정 안 건드리고 바로 되게:** 열 문자·데이터 시작 행 기본값은 실제 내려받은 파일 구조(아래 4번 메모)에 맞춘다. 사용자는 "내려받기 → 파일 열기 → Ctrl+A, Ctrl+C → 지정 셀 클릭 → Ctrl+V" 한 번으로 ✔가 떠야 한다. 설정 칸은 화면이 바뀌었을 때만 고치는 비상용.
   2. **홈택스 숫자와 바로 대조:** 인식 결과에 건수·공급가액·세액·합계를 홈택스 화면과 같은 이름으로 보여주고, 화면 합계를 적는 노란 칸이 있으면 일치 시 "✔ 홈택스와 일치", 다르면 "✖ 차이 n원"을 자동 표시.
   3. **예시 데이터 실수 방지:** 예시는 사업자번호 999- 로 시작하는 가상 자료만 쓰고, 붙여넣기 시트에 999- 행이 남아 있으면 인식 결과에 빨간 경고("예시 데이터 n줄이 남아 있습니다 — 지우고 쓰세요"). 붙여넣기 시트마다 "예시 지우는 법: 8행 아래 전체 선택 → Delete" 한 줄 안내.
   4. **판단은 힌트, 결정은 사람:** 자동 표시는 "후보/확인 필요"까지만. 공제 가능·불가를 단정하는 문구 금지. 최종 결정은 노란 드롭다운(예: 공제로 변경 / 불공제 유지 / 확인 중)으로 사용자가 고른다.
   5. **다음 행동까지 안내:** 결과 시트 끝에 "홈택스에서 바꿀 목록"처럼 사용자가 실제로 해야 할 일만 모아 보여준다 (어느 메뉴에서, 무엇을 검색해, 무엇으로 바꾸는지).
   6. **민감정보 최소 표시:** 카드번호는 결과·점검 시트에 끝 4자리만. 개인 이름 열(사용자명 등)은 결과에 옮기지 않는다.
   7. **지저분한 원본 자동 정리:** 전각 공백(\u3000)·전각 괄호（）·앞뒤 공백·하이픈 차이·"YYYY-MM-DD HH:MM:SS" 날짜·쉼표 있는 금액을 수식으로 정리해 비교한다 (SUBSTITUTE 사용, TRIM만으로는 전각 공백이 안 지워짐).
   8. **넉넉한 행 수:** 붙여넣기 시트는 최소 2,000행까지 수식 준비 (카드 거래처 합산 분기 약 200행, 현금영수증 매출은 분기 수천 행 가능).
   9. **.xls 파일 안내:** 홈택스 내려받기는 .xls라 엑셀에서 '보호된 보기'로 열릴 수 있다 → 사용법 시트에 "노란 막대의 [편집 사용] 누른 뒤 복사" 한 줄.

## 4. 홈택스 화면 구조 메모 (2026-10-08 jade 화면 캡처 기준)

> 양식 만들 때 **열 이름·순서의 기본값**으로 쓴다. 화면 표 기준이며, 엑셀 내려받기 파일은 제목·조회조건 줄이 위에 붙거나 화면 맨 앞 체크박스 열이 빠질 수 있으므로 **붙여넣기 시트에 데이터 시작 행·열 문자 설정 칸은 반드시 둔다.**
> ⚠️ 캡처에 나온 회사명·사업자번호·거래처·금액은 실제 회사 자료다. **양식 예시·블로그 글에 절대 쓰지 않는다** (예시는 전부 가상).

### ① 사업용신용카드 매입세액 공제금액 조회
- 경로: 계산서·영수증·카드 › 사업용 신용카드 사용내역 › 매입세액 공제금액 조회
- 조회조건: 분기별/월별, 연도·분기, 공제여부(전체/공제/불공제)
- 상단 요약 2개 표
  - 매입세액 공제금액 상세내역: 공제대상 | 건수 | 공급가액 | 세액 | 비과세 | 합계 (행: 공제)

   - 홈택스 화면 상단 숫자 입력 노란 칸 3줄: 공제 / 선택불공제 / 당연불공제 각 건수·공급가액·세액 → 파일 합계와 자동 대조 ✔/✖ (카드_공제분 합계 = 공제 행, 카드_전체 합계 = 세 줄 합계)
   - 불공제분(전체 − 공제분, 키 = 카드번호 + 가맹점 사업자번호) 합계
   - 점검 건수: 점검 A / 점검 B / 이중공제 의심 / 현금영수증 확인 건
   - **신고용 합계(수령명세서 참고):** 사업용카드 공제 세액 + 현금영수증 매입 공제 세액, 그리고 드롭다운 선택을 반영한 **변경 후 예상**(공제 늘어나는 세액·줄어드는 세액)
7. **점검A_공제분확인** — 공제로 잡혀 있는데 확인이 필요한 거래처: 유형 간이과세자·면세사업자 / 세액 0원 / 가맹점명·업종 키워드(음식·주점·골프·숙박·여행·주유·차량 등) / 결제대행(PG). 드롭다운: 공제 유지 / 불공제로 변경 / 확인 중.
8. **점검B_불공제확인** — 불공제로 빠져 있는 거래처를 세액 큰 순으로(최대 300곳). 유형 법인사업자·일반과세자이고 세액이 있는 곳이 위로. 확인 포인트 열 + 드롭다운: 공제로 변경 / 불공제 유지 / 확인 중. 상단 안내: "업무 관련 지출인지 확인 후에만 바꾸세요. 접대비·업무무관·개별소비세 과세 승용차 유지비·세금계산서 받은 거래는 바꾸면 안 됩니다."
9. **현금영수증확인** — 현금영수증 매입 중 확인 건: 거래구분에 '취소' 포함 / 부가세 0원 / 업종 키워드 / 공제여부 '공제'인데 세금계산서_매입에 같은 사업자번호가 있음.
10. **이중공제의심** — 카드 공제분·현금영수증 공제분의 사업자번호가 세금계산서_매입에도 있는 거래처: 각각의 금액을 나란히 보여주고 "같은 거래를 두 번 공제했는지 확인" 안내.
11. **홈택스에서 바꿀 목록** — 드롭다운에서 "변경"을 고른 줄만 자동으로 모아서: 어느 화면(사업용카드: 매입세액 공제확인/변경, 현금영수증: 현금영수증 매입내역(지출증빙) 조회의 공제여부 변경)에서, 카드 끝 4자리·가맹점명·사업자번호로 찾아, 무엇으로 바꾸는지.
12. **설정** — 키워드 목록(사용자가 추가 가능한 노란 칸), 결제대행(PG) 이름 목록, 열 설정 비상용.

### 확인 포인트 규칙 (판단이 아니라 힌트)
- 결제대행(PG) 이름(예: 케이씨피, 파이낸셜, 정보통신, 페이먼츠, 이니시스, 다날, 스마트로 등): "온라인 결제 — 카드 명세서·주문내역으로 실제 구매처·품목 확인. 판매처에서 세금계산서를 받은 구매면 불공제 유지가 맞음"
- 유형 간이과세자·면세사업자: "공제 안 되는 유형일 가능성 — 확인"
- 세액 0원: "공제할 세액 없음"
- 음식·주점·골프 키워드: "접대 여부 확인 (거래처 접대면 불공제)" / 숙박·여행: "출장 등 업무용인지 확인" / 주유·정비·주차: "차종 확인 (개별소비세 과세 승용차면 불공제)"
- 그 외: "업무 관련 지출이면 공제 변경 검토"
- 키워드만으로는 음식점을 다 못 잡는다(실제 파일에서 상호만으로 음식점인지 알 수 없는 곳 다수) → 현금영수증은 업종(F열) 키워드를 우선, 카드는 상호 키워드 + 사용자 추가 키워드.

### 검증 메모 (실제 자료로 확인한 사실 — 숫자·상호는 기록하지 않음)
- 카드 '전체' 파일 − '공제' 파일을 카드번호+사업자번호로 빼면, 공제 파일의 모든 줄이 전체 파일에 존재했고 차이 합계가 화면의 선택불공제+당연불공제 합계와 정확히 일치 → 이 계산 방식으로 불공제분을 신뢰성 있게 구할 수 있음
- 선택불공제와 당연불공제는 파일만으로 구분 불가 → 요약에서는 합계로만 다루고, 화면 숫자 입력 칸으로 참고 표시
- 실제 사례에서 불공제 세액의 약 절반이 결제대행(PG) 거래처였음 → PG 안내 문구가 사용자에게 가장 중요한 포인트. 블로그 글에도 "카드 내역에 결제대행사 이름만 찍혀서 무엇을 샀는지 모르는 문제"를 공감 포인트로 활용(실제 숫자는 쓰지 말 것)
- 현금영수증 조회는 홈택스에 등록한 발급수단으로 받은 것만 나옴(화면 안내) → 직원 개인 번호로 받은 지출증빙 누락 가능성을 사용법·글에 안내
