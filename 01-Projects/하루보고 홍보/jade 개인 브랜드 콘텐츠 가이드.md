# jade 개인 브랜드 콘텐츠 가이드

> 2026-10-04, jade가 가져온 "브랜드 전략 프롬프트"(허세→신념→실행→증거→미래 루프)를 하루보고 상황에 맞게 압축한 것.
> **적용 무대: 쓰레드(주력) + 티스토리(보조).** 하루보고 사이트와 네이버 하루보고 블로그에는 적용하지 않는다 — 거긴 제품이 주인공이고, 검증된 전환 흐름("파일만 올리면 보고서 완성")을 지킨다.

## 포지셔닝 한 문장

**"직장생활 20년차 재무담당자가, 코딩 없이 AI로 자기 서비스를 만들어가는 과정을 숫자까지 공개하는 기록."**

- 성공담이 아니라 **성공하기 전부터 쓰는 기록**이라는 점이 차별점
- 키워드: 기록 · 실행 · AI · 직장생활 · 실패 · 결과 (억지로 다 넣지 않기)

## 브랜드 루프 (모든 콘텐츠의 뼈대)

선언("이렇게 할 것이다") → 행동("오늘 이것을 했다") → 기록(과정 공개) → 결과(숫자로 확인) → 개선(실패하면 수정) → 증명 → 더 큰 선언

## 콘텐츠 3축

### A. 선언(허세) — 관심을 만든다
- 내가 감당할 수 있는 수준까지만 크게 말한다. 선언 뒤에는 반드시 **현재 상태 + 행동 계획**을 붙인다.
- 예: "직장생활 20년차에 두 번째 직업을 만들고 있습니다. 지금은 가입자 23명. 그래서 오늘도 기능 하나를 고쳤습니다."

### B. 신념 — 캐릭터를 만든다
- 모든 사람에게 좋은 말 하지 않기. 내 경험으로 증명할 수 있는 주장만.
- 구조: 문제 제기 → 내 주장 → 이유 → 내 경험 → 반대 의견 인정 → 그래도 내가 선택한 행동
- jade의 신념 후보: "일기 실패는 의지가 아니라 방법 문제다" / "AI를 공부하는 사람보다 AI로 뭔가 만든 사람이 이긴다" / "동기부여보다 시스템이다(알림·루틴·자동화)"

### C. 결과 — 신뢰를 만든다 (가장 중요)
- **월간 결산 쓰레드**: 가입자·보고서 수·발행한 글 수·실패·다음 달 목표를 실제 숫자로 공개. 매월 초 1회.
- 좋은 숫자만 공개하지 않는다. 심사 탈락, 안 늘어난 주간도 그대로 쓴다 — 실패가 신뢰 자산.

## 홍보 공식 (글마다 하나 선택)

- **A 도발형**: 도발적 주장 → 이유 → 직접 해본 경험 → 결과 → 링크
- **B 실패형**: 실패 → 깨달음 → 재시도 → 변화 → 과정은 하루보고에
- **C 선언형**: 미래 선언 → 현재 상황 → 할 행동 → 공개 검증 약속
- **D 반박형**: 상식 반박 → 내 신념 → 실제 행동 → 결과 → 독자 질문

## 제목 원칙

- 검색형(티스토리·네이버): 정보가 명확하게 — "재무담당자가 AI로 업무 자동화한 30일 기록"
- SNS형(쓰레드): 호기심 우선 — "두 달 전엔 보고서 하나였는데, 어느새 이렇게 됐습니다"

## 절대 금지 (원문 그대로 유지)

허위 방문자·허위 수익·가짜 후기·가짜 경력·존재하지 않는 성과·AI가 지어낸 경험담·신념 없는 논란·커뮤니티 도배·저품질 대량생산. **실제 숫자, 실제 경험만.**
