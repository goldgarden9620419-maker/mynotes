# 하루보고 홍보 숏폼 1호 — 파일 변신 (2026-10-22)

- **완성본**: `하루보고 홍보 숏폼 1호 (2026-10).mp4` (17.5초, 1080×1920 세로, 30fps, h264, 약 1MB, 무음)
- **용도**: 쓰레드·인스타 릴스·유튜브 쇼츠 공용. 무음이므로 올릴 때 앱에서 음악을 입히면 된다.
- **구성**: ① 훅 "매일 저녁, 보고서 정리에 30분씩 쓰세요?" ② 파일 → 1분 → 대표님 보고서 변신 ③ 가치 3줄(똑같은 양식·숫자 안 지어냄·hwp 변환) ④ 파란 화면 마무리(하루보고 · 가입 없이 바로 체험 · harubogo.vercel.app)
- **톤**: 랜딩과 동일 — Pretendard + 브랜드 블루(#3182f6 계열), 모션도 랜딩 히어로 데모와 같은 문법

## 다시 만들거나 고치는 법 (클로드에게 맡기면 됨)

소스는 이 폴더의 `promo.html`(장면·문구·타이밍 전부 이 파일 하나) + `render.mjs`(렌더 스크립트).

1. 작업 폴더에 두 파일 복사 후 `npm i playwright ffmpeg-static pretendard`
2. `promo.html`의 폰트 경로가 `node_modules/pretendard/...`를 가리키는지 확인
3. `node render.mjs` → `harubogo-promo.mp4` 생성

문구·장면 길이는 `promo.html` 안의 타임라인 숫자(ms)만 바꾸면 된다. 2호를 만들 때 이 구조를 그대로 재활용.
