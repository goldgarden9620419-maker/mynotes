# 숏폼 2호 기획 — "하루쉼표: 대화로 쓰는 일기" (2026-10-23)

> 상태: 기획안 (jade 승인 대기) · 제작 방식: 1호와 동일(컨테이너 렌더, 비용 0원)

## 포지셔닝

- 1호 = 보고서 변신(효율) → **2호 = 하루쉼표(감성)** — 서비스의 두 번째 기둥
- 미션 직결: "직장인이 일기를 쓰는 건 정말 어렵다" → 그래서 대화로 만들었다
- 쓰레드 피드에서 1호와 톤이 달라 겹치지 않음

## 구성 (약 18초, 1080×1920 세로, 무음)

1. **훅 (0~3.5초)**: "일기, 쓰고 싶은데" → "퇴근하면 기운이 없죠" 🌙 — 저녁 감성(어두운 남색+브랜드 파랑)
2. **대화 (3.5~9초)**: 채팅 말풍선 순차 등장 — 나: "오늘 보고 끝내고 미팅, 저녁엔 산책했어" / 하루쉼표: "수고했어요, 산책은 어땠어요?"
3. **정리 (9~13.5초)**: 두 카드 — "업무는 → 📅 일정으로" / "마음은 → 🌙 일기로" (+작은 배지: 사진·PIN 잠금·월간 인쇄)
4. **마무리 (13.5~18초)**: "하루 5분, 대화로 쓰는 일기" → 하루보고 · harubogo.vercel.app
