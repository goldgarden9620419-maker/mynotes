# 후보 A — BM 설계서: 업무일지 → 재무보고 자동 변환 SaaS

> 작성일: 2026-08-31 · 부록 1 「아이디어를 수익 구조로 바꾸는 1분 프롬프트」 적용 결과
> 상위 문서: [[온라인 건물주 - 나만의 SaaS 실행 로드맵]] (1주차 산출물)
> 다음 단계: 이 설계서 6개 섹션 전체를 복사 → PRD 생성 (부록 2)

## 입력한 아이디어 데이터

- **한 줄 요약**: 경리·재무 담당자가 매일 쓰는 업무일지(PDF·엑셀)를 올리면 대표 보고용 재무보고서가 1분 만에 나오는 서비스
- **떠오른 이유**: 에이팜건강에서 매일 업무일지를 수기로 재무보고로 옮기는 작업을 직접 AI 자동화로 해결한 실전 경험
- **주요 사용자**: 중소기업(5~50인) 경리·재무 담당자, 경리 없이 직접 챙기는 소기업 대표
- **현재 해결법**: 엑셀 복붙 수작업, 워드/한글 보고서, 카톡 보고
- **핵심 기능 1가지**: 업무일지 업로드 → 정해진 양식의 재무보고서 자동 생성

## 1. 🎯 타깃 고객 정의 (Who)

**가장 절실한 사람**: 직원 5~50인 중소기업에서 경리·총무·인사를 혼자 겸직하는 재무 담당자 (그리고 그 보고를 매일 기다리는 대표)

핵심 고통 3가지:
1. **매일 아침 보고 짜깁기** — 은행·쇼핑몰 정산·카드·ERP에 흩어진 숫자를 엑셀 여러 파일에서 복붙해 대표 보고 한 장을 만드는 데 매일 30분~1시간. 매일 반복되는데 누가 대신 못 해줌
2. **숫자 하나 틀리면 하루가 날아감** — 수작업 복붙이라 누락·오타가 생기고, 대표가 "이 숫자 왜 안 맞아?" 한마디 하면 원인 추적에 반나절
3. **사람에게 종속된 보고** — 담당자가 휴가·퇴사하면 보고가 멈춤. 양식과 노하우가 개인 머릿속에만 있음

## 2. 💰 수익 모델 설계 (How to Make Money)

| 방법 | 구조 | 가격 |
|---|---|---|
| ① 월 구독 (주력) | 무료: 월 3건 변환, 기본 양식 1종 → 프로: 무제한 변환 + 커스텀 양식 + 아카이브 검색 + 월간 요약 리포트 | 월 29,000원 |
| ② 온보딩 셋업 (일회성) | 회사의 기존 보고 양식을 그대로 복제해주는 커스텀 매핑 설정 대행 | 99,000원~ |
| ③ B2B 라이선스 | 세무사무소·프랜차이즈 본부가 여러 고객사/가맹점을 한 번에 처리 | 월 150,000원~ (10개사 단위) |

**유료 전환 유도 장치**: "매일 쓰는" 서비스인데 무료는 월 3건 — 한 주도 못 버팀. 3건 안에 "내 일이 1분으로 줄어드는" 경험을 시키는 게 전부.

### 가격 적정성 검증 (2026-08-31 시장 조사)

| 경쟁/유사 서비스 | 월 가격 | 비고 |
|---|---|---|
| 이카운트 ERP | 40,000원 (VAT별도) | 전 기능·사용자 무제한 + 가입비 20만원 |
| 경리나라 (웹케시) | 49,000~69,000원 (VAT별도) | AI형 59,000~79,000원 / 다중사업자 299,000원 / 가입비 50만원(프로모션 면제) |
| 자비스 AI 경리 | 33,000원 (VAT별도) | 세무대행 패키지는 80,000원~ |
| 캐시노트 멤버십 | 9,900 / 16,500 / 33,000원 (VAT포함) | 소상공인 대상 3단계 티어 |
| 일반 세무사무소 기장 | 100,000원~ | 사람이 하는 대행 |

**판단**:
- 29,000원은 자비스(3.3만)·이카운트(4만)·경리나라(4.9만~) 바로 아래, 캐시노트 상위 티어(3.3만)와 비슷한 위치 — "경리 SaaS는 월 3~7만 원"이라는 가격 인식이 이미 시장에 형성돼 있어서 저항 없는 구간
- 가치 기준으로도 성립: 매일 30~60분 절약 = 월 10~20시간 = 인건비 환산 월 10~20만 원 → 29,000원은 제공 가치의 15~30% 수준
- 이 시장은 가입비/셋업비가 표준 관행 (이카운트 20만, 경리나라 50만) → 온보딩 셋업 99,000원은 오히려 싼 편. 150,000원까지 여지 있음
- B2B 150,000원(10개사)은 경리나라 다중사업자형(299,000원/5개사)의 절반 이하 — 세무사무소 영업 시 비교 우위 명확

**최종 가격안 (수정)**:
- 스타터 월 **9,900원** (월 10건, 기본 양식) — 결제 문턱을 낮추는 진입 티어 (캐시노트 방식)
- 프로 월 **29,000원** (VAT별도, 무제한+커스텀 양식+아카이브) — 주력. 런칭 특가: 첫 100명 월 19,900원 평생 고정
- 온보딩 셋업 **150,000원** (런칭 기간 99,000원)
- B2B 월 **150,000원**~ (10개사)

⚠️ 단, 최종 확정은 조사가 아니라 **베타 10명의 지불 의사로 검증**: "월 19,900원이면 쓰시겠어요? 29,000원이면요?" 두 가격 반응 비교 후 결정.

**플랜별 기능 차별화 (2026-09-02 확정, 구현 완료)**:
- 무료/스타터: 텍스트형 PDF·엑셀·붙여넣기 변환
- **프로 전용**: ① 무제한 변환 ② 커스텀 양식 ③ **스캔본 PDF 판독(AI 비전)** ⭐
  - 스캔본은 AI가 문서를 이미지로 직접 판독 → 원가가 2~3배라 프로 전용이 수익 구조상으로도 타당
  - 팩스 거래명세서·종이 장부 스캔이 많은 업체(전통 제조·유통)에게 강력한 업그레이드 유인

## 3. ⚔️ 경쟁 분석 (Why Me)

| 대체재 | 치명적 약점 |
|---|---|
| 더존·이카운트·경리나라 (ERP) | 무겁고 비싸고 도입 교육 필요. 정작 **"대표 보고서 한 장"이라는 마지막 1마일은 안 해줌** — 결국 ERP에서 뽑아서 또 엑셀 복붙 |
| 크몽 외주 매크로/엑셀 자동화 | 일회성 납품. 양식·소스가 바뀌면 깨지고 유지보수 없음 |
| ChatGPT에 직접 붙여넣기 | 매번 프롬프트 재작성, 양식 일관성 없음, 재무 데이터를 해외 AI에 그대로 넣는 보안 불안 |

**내 틈새**: "쓰던 업무일지를 바꾸지 마라, 그대로 올려라." 도입 교육 0분. 이 변환 규칙은 상상이 아니라 **실제 법인 재무보고 실무에서 매일 돌려본 검증된 로직** — 섹션 매핑, 날짜별 아카이빙, 대표가 실제로 보고받고 싶어하는 문구까지 내장.

## 4. 🚀 MVP 기능 리스트 (What to Build First)

딱 3가지:
1. **파일 업로드(PDF/엑셀) → 표준 재무보고서 자동 생성** (고정 양식 1종)
2. **날짜별 아카이브 + 검색** (지난 보고 다시 찾기)
3. **보고서 내보내기** (PDF 다운로드 + 카톡 공유용 링크)

나머지(커스텀 양식 빌더, 은행 API 연동, 대시보드, 팀 승인 플로우)는 전부 **'나중에'**.

## 5. 📣 첫 고객 100명 확보 전략 (Go-to-Market, 광고비 0원)

1. **1주차 — 베타 10명**: 네이버 경리·총무 카페, 오픈카톡 커뮤니티에 "업무일지 올리면 재무보고 만들어주는 도구 무료 베타" 모집 (피드백 조건)
2. **2~4주차 — 콘텐츠 엔진 가동 (온라인)**: 이미 보유한 쓰레드+블로그 파이프라인으로 "경리 업무 자동화" 연재 → 리드마그넷 "대표 보고용 재무보고 엑셀 템플릿 무료 배포" → 템플릿 쓰다 보면 "이걸 자동으로?" → 가입 유도
3. **병행 — 크몽 역진입**: 크몽에 '재무보고 자동화 셋업' 서비스(건당)를 등록 → 구매자를 월 구독으로 업셀 (책의 크몽 역분석을 판매 채널로 뒤집기)
4. **오프라인**: 거래하는 세무사무소부터 시작해 지역 세무사무소 3곳에 데모 — 기장 고객사 수십 곳을 가진 최고의 소개 채널

## 6. ⚠️ 치명적 약점 (Devil's Advocate)

1. **회사마다 업무일지 양식이 제각각** → 파싱 실패가 잦으면 첫 경험에서 바로 이탈
   - 대응: MVP는 "우리 템플릿에 붙여넣는 방식"부터 시작해 실패율 0에서 출발, 커스텀 양식은 유료 온보딩(수익 모델 ②)으로 흡수
2. **재무 데이터를 외부 서비스에 올리는 것에 대한 불신**
   - 대응: 처리 후 원본 자동 삭제 옵션, 국내 서버 명시, 개인정보처리방침·보안 페이지를 첫날부터 갖추기. 초기엔 계좌번호 마스킹 가이드 제공
3. **결제 권한이 사용자에게 없음** — 경리 담당자는 편해지고 싶지만 회사 카드 결제는 대표 승인 필요
   - 대응: 마케팅 메시지 이원화 — 담당자에겐 "매일 1시간 절약", 대표에겐 "담당자가 없어도 보고는 나온다". 월 29,000원 = 점심 한 끼 프레임
   - (+) ERP 대기업이 AI 보고 기능을 붙일 가능성 → 초저가·5분 셋업·이커머스 셀러 버티컬로 틈새 고수
