## 🔁 제품별 반복 루틴 (30분)

1. **제품 선택** — 쿠팡 파트너스(partners.coupang.com) → 링크 생성 → 상품 검색
   - 기준: 로켓배송 / 리뷰 500+ / 평점 4.5+ / 1~3만 원대 / 작동 장면이 있는 제품
   - **단축 링크 복사** (`link.coupang.com/a/...`) + 상세페이지 **제품 사진 2~3장 저장**
2. **AI 영상 생성** — Claude에게 사진 첨부 + "이 제품으로 광고 영상 만들어줘"
   - 키비주얼 이미지 → 한국어 대사 12초 영상 (약 108크레딧)
   - 완성되면 브라우저에서 우클릭 → 저장
3. **자동 편집** — `문서\coupang_ad_editor\run.bat` 더블클릭
   - 제품 정보 입력 (URL 칸에 **파트너스 링크**) → 영상 업로드
   - 1단계 AI 분석 → 2단계 렌더링 (출력 방식: **CapCut으로 이어서 편집**)
4. **자막** — CapCut PC: 새 프로젝트 → 가져오기 `output\제품명\capcut\tiktok\tiktok_cut.mp4`
   - 텍스트 → 자동 캡션(월 2회 무료, 소진 시 같은 폴더의 SRT 가져오기) → 오타 수정 → 내보내기
   - instagram 폴더의 `instagram_cut.mp4`로 한 번 더
5. **업로드**
   - 틱톡: "틱톡에 올려줘"라고 Claude에게 요청하면 자동 게시 (연동 완료됨) 또는 tiktok.com 수동
   - 인스타: instagram.com → 만들기 → **AI 레이블 ON** → 공유
   - 게시글 문구: `output\제품명\capcut\...\*_caption.txt` 복사-붙여넣기 (파트너스 문구 포함, 지우지 말 것)
   - 캡션의 음성인식 오타 확인 (예: 한절기→환절기)
6. **링크트리** — linktr.ee/admin → Add → 파트너스 링크 + 제목 "제품명 - 쿠팡에서 구매" → 맨 위로
