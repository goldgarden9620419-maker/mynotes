## 1. 배포 (무료로 가능)
현재 `index.html`은 서버·빌드 없이 동작하는 순수 정적 파일이라 아래 방식으로 바로 배포 가능:

1. **정적 호스팅 선택**: Vercel, Netlify, Cloudflare Pages 중 하나 (모두 무료 티어 + HTTPS 자동 + 커스텀 도메인 지원)
2. **실제 웹사이트용 GitHub 저장소 생성** (이 Obsidian vault와는 별도 저장소로 분리 권장 — vault는 기획/데이터 관리용, 배포 저장소는 실제 서비스 코드용)
3. `index.html`, `celebrities.json`, `ohang_copy.json`을 그 저장소로 이동 + Vercel/Netlify에 연결 → push할 때마다 자동 배포
4. **도메인 구매**: 가비아/후이즈/Namecheap 등에서 연 1~2만원대 구매 (예: `내사주유명인.com` 류), Vercel/Netlify에 연결

## 2. 애드센스 신청 요건
- **개인정보처리방침 페이지** (필수) — 방문자 데이터 처리 방식 명시
- **이용약관 페이지** (권장)
- **소개(About)/문의(Contact) 페이지** — 사이트 신뢰도 판단에 도움
- **콘텐츠 충실도**: 사주 풀이만 있으면 "낮은 가치 콘텐츠"로 반려될 수 있음 → 지금처럼 유명인 스토리·습관·모토가 함께 있는 게 유리. 각 유명인을 개별 페이지(URL)로 만들면 콘텐츠 양도 늘고 SEO에도 도움
- 승인까지 보통 며칠~몇 주 소요, 트래픽이 적어도 신청 자체는 가능하지만 콘텐츠 품질이 핵심 심사 기준

## 3. 트래픽 확보 전략 (수익의 실질적 관건)
- **카드 공유 기능**(이미 구현됨)을 통한 SNS 바이럴이 핵심 — 인스타 스토리/쓰레드/카카오톡 공유 유도
- **SEO**: "OOO 사주", "OOO 일주" 같은 유명인 이름 기반 검색 유입을 노리려면 유명인별 개별 URL/페이지 구조 필요 (지금은 SPA라 검색엔진이 개별 결과를 못 찾음)
- 이미 쓰레드/블로그 콘텐츠 제작 워크플로우가 있으니, 사주 유형 콘텐츠를 블로그·쓰레드에 연계해 유입원으로 활용 가능
