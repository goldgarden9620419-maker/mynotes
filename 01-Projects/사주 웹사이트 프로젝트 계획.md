# 사주 웹사이트 프로젝트 계획

## 1. 컨셉 & 차별화 포인트
- 기본: 생년월일시 기반 사주(사주팔자) 풀이 제공
- **핵심 차별화**: 사용자의 사주(일주/오행 구성 등)와 유사한 **유명인 매칭**
  → "당신과 비슷한 사주 유형의 인물: OOO"
- 매칭된 유명인이 성공하기까지 가진 **습관 / 행동 / 마음가짐**을 정리해서 보여줌
- 유명인의 **모토(좌우명)를 카드 형식(UI)**으로 제공 → SNS 공유하기 좋은 포맷
- "사주 풀이 + 동기부여 콘텐츠"를 결합한 자기계발형 사주 사이트

## 2. 타겟 사용자
- 20~30대, 사주/운세에 관심 있지만 자기계발·동기부여 콘텐츠도 좋아하는 층
- SNS(인스타/쓰레드) 공유를 통한 바이럴 유입 기대 가능

## 3. 핵심 기능 (MVP 기준)
1. **사주 계산**: 생년월일시 입력 → 사주팔자(년/월/일/시주), 오행 분포 출력
2. **유명인 매칭**: 사용자의 일주(또는 오행 우세 유형) 기준으로 유사한 유명인 1~3명 매칭
3. **유명인 카드**: 유명인별 성공 스토리 요약 + 습관/마인드셋 + 모토를 카드 이미지 형태로 제공 (공유 버튼 포함)
4. **결과 공유**: 카카오톡/인스타 스토리용 이미지 공유 기능 (바이럴 핵심 기능)
5. (선택) 상세 풀이 잠금 → 이메일 수집 또는 광고 시청 후 열람 등 수익화 연계

## 4. 콘텐츠/DB 설계 개요
- **사주 계산 로직**: 만세력(음력 변환, 절기 기준 월주 계산) 필요 → 기존 오픈소스 라이브러리/API 활용 검토 (직접 구현 시 정확도 검증 필요)
- **유명인 DB**: 생년월일(공개된 정보) + 사주 유형 + 성공 스토리 요약 + 습관/모토
  - 초기엔 수십~백 명 규모로 직접 큐레이션 필요 (콘텐츠 제작 리소스 소요)
  - ⚠️ 실존 인물 정보이므로 **사실관계 검증**이 중요, "사주 덕분에 성공했다"는 식의 인과관계 주장은 피하고 "비슷한 사주 유형을 가진 인물의 실제 습관/모토" 정도로 톤 조절 필요

## 5. 수익화 전략
- **기본**: 구글 애드센스 (트래픽 확보가 핵심 관건)
- **추가 수익원 (선택)**:
  - 상세 사주 풀이 유료화 (소액 결제)
  - 제휴마케팅(운세 앱, 심리테스트 앱 등)
  - 유명인 카드 세트 굿즈/이미지 판매

## 6. 기술 스택 제안 (예시)
- 프론트: Next.js (SEO 유리, 정적 생성 가능)
- 사주 계산: 만세력 라이브러리(예: lunar-javascript 등) 또는 자체 로직
- 배포: Vercel (무료 티어로 시작 가능)
- 카드 이미지 생성: Canvas API 또는 html-to-image

## 7. 리스크 & 유의사항
- **애드센스 승인**: 운세 콘텐츠는 승인 가능하나 콘텐츠 품질(단순 자동생성 아님), 개인정보처리방침/이용약관 페이지 필수
- **저작권/명예훼손 리스크**: 유명인 정보는 공개된 사실 기반으로만 작성, 과장/허위 서술 주의
- **사주 계산 정확도**: 만세력 계산이 틀리면 신뢰도 크게 하락 → 검증 중요
- **콘텐츠 제작 리소스**: 유명인 DB 큐레이션이 초기 가장 큰 작업량

## 8. 단계별 로드맵
1. **1단계 (MVP)**: 사주 계산 + 유명인 매칭 20~30명 DB + 카드 UI → 애드센스 신청
2. **2단계**: SNS 공유 최적화로 트래픽 확보, 유명인 DB 확장(100명+)
3. **3단계**: 유료 상세풀이/제휴마케팅 등 수익원 다각화
