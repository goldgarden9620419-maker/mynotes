```
맛집을 검색하면 광고와 프랜차이즈가 먼저 나와서, 직접 만들었어요.

■ 이런 게 돼요
- 내 위치 또는 동네·역 이름(예: 동성로, 강남역)으로 검색
- 스타벅스·맥도날드 같은 대형 프랜차이즈 50여 개 자동 제외
- 별점과 후기 수를 함께 봐서, 후기 몇 개짜리 5점 가게에 휘둘리지 않게 정렬
- 모임 성격(가족·데이트·회식·혼밥)을 검색에 반영
- 검색 결과를 링크로 친구에게 공유하면 같은 조건으로 바로 열림
- 길찾기는 자동차·대중교통·도보 골라서 카카오맵으로

■ 직접 다녀온 기록도 같이
대구에서 가족과 직접 다녀온 가게는 결제 영수증, 1인분 그램 계산, 대기·주차까지 정리해서 올리고 있어요.

■ 만든 방법
Next.js + Google Places API, Vercel 배포. 기획은 ChatGPT, 검증과 구현은 Claude와 함께 했어요.

써 보시고 불편한 점이나 "이런 기능 있으면 좋겠다"는 댓글 주시면 바로 고칠게요 🙏
```

## ② 메이커로그 문구 (가설 → 시도 → 결과·배운 점 → 앞으로)
제목: 맛집 검색에서 프랜차이즈를 빼 봤더니 — 1인 사이드 프로젝트 숨은맛집찾기 기록
```
■ 가설
"근처 맛집"을 검색하면 광고 상위 노출과 프랜차이즈가 대부분이다. 동네 사람만 아는 가게를 찾고 싶은 수요가 있을 것이다.

■ 시도
- 위치 + 인원 + 모임 성격 + 음식 종류만 고르면, 대형 프랜차이즈를 빼고 별점·후기 수 기준으로 최대 8곳을 보여주는 웹을 만들었어요.
- 위치 권한을 거부하거나 PC에서도 쓸 수 있게 '동네·역 이름 검색'을 넣었고,
- 맛집은 혼자 고르지 않으니 '검색 결과 공유 링크'를 만들었어요.
- 검색만으로는 신뢰가 부족해서, 제가 가족과 직접 다녀온 대구 가게는 영수증·그램 계산·주차까지 기록한 글로 붙였어요.

■ 결과와 배운 점
- 쓰레드에 같은 사람이 같은 맛집 글을 올려도, 본문 링크를 빼고 주제 태그(#대구맛집)를 달자 조회수가 약 10배(57 → 555) 차이가 났어요. 링크는 첫 댓글로.
- "어디 가세요?" 같은 열린 질문엔 댓글이 안 달렸어요. 다음엔 1·2·3 중 고르는 질문으로 바꿔 보는 중이에요.
- 길찾기를 카카오맵 웹으로 열면 대중교통 경로가 기본이라 자차 사용자가 불편했어요 → 자동차·대중교통·도보를 고르게 바꿨어요.

■ 앞으로
- 직접 다녀온 기록을 주 1편씩 늘리고
- 써 주신 분들 피드백으로 기능을 고쳐 나갈게요.

👉 https://www.matjipfinder.com
여러분 동네에서 한 번 검색해 보시고, 결과가 이상하거나 아쉬운 점 댓글로 알려주세요!
```
