# 하루보고 — 월간 요약 리포트 기획 (확정)

> 확정일: 2026-09-04 · 구현 예정: 9월 말~10월 초 (한 달치 데이터가 쌓인 뒤)
> 프로 전용 기능 — 29,000원의 핵심 이유

## 한 줄 정의

한 달 동안 만든 일일 보고서들을 모아, **중요 이슈의 처리 여부까지 담긴 월간 종합 보고서 1장**을 자동 생성한다.

## 핵심 구조 3단계 (jade 추가 기획 반영)

### 1단계 — 이슈 자동 수집 (매일)
- 일일 보고서를 만들 때마다, 특이사항의 **"확인 필요" 항목이 자동으로 이슈 목록에 쌓인다**
- 사용자가 따로 입력할 필요 없음 — 보고서만 만들면 자동 축적

### 2단계 — 완료 체크 (수시)
- 보고서 화면과 대시보드에 **"이번 달 확인할 일"** 목록 표시
- 각 이슈 옆 체크박스 — 클릭 한 번으로 **완료 / 미해결** 표시
- 예: "거래처 외상대 문의" → 처리 후 ✓ 체크

### 3단계 — 월간 리포트 생성 (월말/월초)
- 보관함의 **"지난달 요약 리포트 만들기"** 버튼 (그달 보고서 5건 이상일 때)
- 리포트 내용:
  1. 월 매출 합계 + 주차별 추이
  2. 입·출금 총액
  3. 채널별 매출 비중
  4. **중요 이슈 결산: 이번 달 이슈 N건 중 완료 n건 / 미해결 m건** (미해결은 강조 표시, 다음 달로 이어짐)
  5. 전월 대비 증감
- 2단계(추후): 매월 1일 자동 생성 + 알림

## 데이터 설계 메모

- `issues` 테이블: 보고서 생성 시 "확인 필요" 항목 자동 insert (user_id, report_id, 내용, 상태, 생성일, 완료일)
- 월간 리포트도 reports 테이블에 저장 (source_type 구분) → 보관함·다운로드·공유 그대로 재사용

## 왜 프로 전용의 핵심인가

- 일일 보고서 = 담당자의 시간 절약
- 월간 리포트 = **대표가 진짜 기다리는 것** + 이슈가 관리되고 있다는 증거
- "확인 필요 → 완료 체크 → 월말 결산" 루프는 경쟁 서비스에 없는 실무자 관점 기능

## 구현 시점

- **9월 말~10월 초**: 유저들의 9월 데이터가 쌓인 뒤 구현 → 10월 1일 "9월 리포트" 첫 제공
- 결제 오픈 시점과 맞물리게 — 프로 전환 설득 카드로 사용
- 그때 클로드에게: **"월간 리포트 만들자"**
