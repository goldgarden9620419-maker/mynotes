# 네이버 블로그 운영 자동화 - 프로젝트 계획

> [!info] 개요
> 사진 몇 장 + 한 줄 메모 → 네이버 SEO 글 자동 초안 + 임시저장까지 해주는 툴을 내 PC에 구축하고, 주 2~3회 발행 루틴을 정착시킨다.
> Notion 프로젝트 페이지: 라이프 대시보드 → 🤖 네이버 블로그 운영 자동화

## 프로젝트 구분

- **이 프로젝트 (네이버)**: 애드포스트 · 체험단/협찬 선발 · 지역/브랜드 마케팅 축
- **수익형 블로그 프로젝트 (별도)**: 티스토리 · 구글 애드센스 승인 축
- 장기 목표: 같은 소재(사진+메모) 하나로 **네이버 + 티스토리 + Threads 3채널**에 뿌리는 구조

## 진행 로드맵 — 5가지 활용 다 하기

활용처: ① 글 자동화 ② 체험단·협찬 ③ 스타일 복제 ④ 3채널 확장 ⑤ 에이팜건강 마케팅. 동시에 5개가 아니라 툴 하나 세우고 단계적으로 확장한다.

### Phase 0 · 툴 구축 (이번 주말, ~1시간)

1. 개인 리뷰 블로그(맛집·생활)로 시작 — 소재 확보 쉽고 실패 부담 없음
2. PC 설치 (프롬프트 문서의 STEP 0)
3. 계획 모드(plan mode)로 프롬프트 실행 → 툴 제작
4. 첫 /write 테스트 글 검수

### Phase 1 · 개인 리뷰 블로그 루틴 (1~4주차) → 활용 ①③

- 주 2~3회 발행 (평일 저녁 30분이면 충분 — 나머지 시간은 애드센스 프로젝트 유지)
- 매주 상위노출 글 2~3개를 /learn-style · /analyze-trends에 학습
- 초안 검수 때 말투·구성 피드백 → 툴이 파일로 축적

### Phase 2 · 체험단 지원 + 3채널 확장 (5~8주차) → 활용 ②④

- 글 15편+ 쌓이면 체험단 플랫폼(레뷰, 디너의여왕 등) 지원 시작
- 같은 소재(사진+메모)를 티스토리 승인글·Threads 파이프라인에 재가공 — 복붙 금지, 채널별 재구성(유사문서 방지)
- 협찬 글 시작되면 표기 자동 포함 확인

### Phase 3 · 에이팜건강 회사 블로그 (2~3개월차) → 활용 ⑤

- 반드시 **별도 계정 + 별도 폴더(두 번째 인스턴스)** — C-Rank는 블로그 하나에 주제 하나. 개인 리뷰와 회사 콘텐츠를 섞으면 둘 다 손해
- 건강기능식품 광고 표현 규제(사전 심의)를 제작 인터뷰에서 CLAUDE.md 규칙으로 명문화
- 회사 블로그 운영 권한·방향은 사전 확인

## 🔁 발행 루틴 (글 1편마다 반복 — 주 2~3회)

> 작업 장소: PC 터미널. `C:\대구맛집블로그` 폴더에서 터미널 열고 `claude` 실행.
> **시작 방법: 코치 세션(Claude)에 "블로그 루틴 시작"이라고 말하면 터미널 열기부터 발행까지 단계별로 안내받는다.** 발행 완료 시 코치가 진행 로그에 편수 기록 (15편 도달 시 체험단 지원 단계 시작).
> **자동 알림: 매주 토요일 오후 6시(KST)에 코치가 먼저 "루틴 시작할까요?"라고 알림** (2026-09-03 설정, 평일 외식 때는 언제든 수동으로 "블로그 루틴 시작" 가능).

1. [ ] 외식 때 사진 5~10장 촬영 (음식 클로즈업·간판·내부·메뉴판 골고루)
2. [ ] 폰 사진 → PC로 옮기기 (카톡 나에게 보내기 / MYBOX) → `C:\대구맛집블로그\input\photos\`에 복사
3. [ ] 터미널에서 `claude` 실행 → `/write 지역+식당명, 내돈내산(또는 협찬), 한 줄 감상`
4. [ ] 초안 검수: 말투가 내 것 같은지 / 사실이 맞는지 / 페르소나·키워드 확인 → 교정 피드백 주면 파일로 축적됨
5. [ ] 승인 → 임시저장 → "자동 처리 결과" 블록 확인 (태그/지도/소제목 ✅ 여부)
6. [ ] 네이버 "저장 글"에서 최종 확인 → **발행 버튼 직접 클릭**
7. [ ] 발행 후 24시간 수정 금지, 하루 2건 이상 금지

**주 1회 추가 루틴**: 내 분야 상위노출 글 2~3개를 `/learn-style` · `/analyze-trends`에 학습시키기.
