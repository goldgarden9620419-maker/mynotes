## 우선순위

### 1순위 — 네이버 블로그 "양식 배포" 글 ✅ 준비 완료

- ⚠️ **자동 발행 불가 확정 (9/5 조사)**: 네이버가 블로그 글쓰기 API를 2020년 5월 종료 (광고성 자동 포스팅 차단). 브라우저 자동 조작은 계정 보호 차단 + 저품질 위험이라 하지 않기로 함 → **발행은 복붙으로 수동 (글당 5분)**
- ✅ 대신 **양식 다운로드 페이지 개설**: https://harubogo.vercel.app/templates — 블로그·카톡·쓰레드 어디서든 이 링크 하나로 양식 배포 + 게스트 체험 유도
- 노리는 검색어: 업무일지 양식 / 자금일보 양식 / 대표 보고서 양식
- 방식: 무료 엑셀 양식 나눔 글 → 글 끝에 "이 양식 그대로 올리면 보고서 자동 완성" 하루보고 소개
- 장점: 검색 유입이라 한 번 쓰면 계속 들어옴, 필요한 사람만 와서 전환율 높음
- **준비된 것** ([[하루보고 홍보]] 폴더):
  - 업무일지 양식 (무료배포).xlsx / 일일 자금일보 양식 (무료배포).xlsx
  - 블로그 글 1 - 업무일지 양식 나눔.md (복붙용 완성본)
  - 블로그 글 2 - 자금일보 양식 나눔.md (글 1에서 3~4일 뒤 발행)
- **✅ 주간 자동 루틴 등록 (9/5)**: 매주 토요일 18:00, 클로드가 새 홍보 글(필요 시 배포 양식까지) 자동 준비 → 홍보 폴더에 저장 (맛집 루틴과 같은 시간, 별도 루틴 trig_014Cw24qayEetWiNgPTxQLGc). 발행만 복붙으로 수동 (네이버 API 종료로 자동 발행 불가)
- **운영 방침: 하루보고 전용 새 네이버 블로그** (맛집 블로그와 분리 — 주제 일관성이 검색 노출에 유리)
- [ ] jade: 하루보고 전용 새 네이버 블로그 개설 → 주소를 클로드에게 알려주기
- [ ] jade: 새 블로그에 글 1 발행 (본문 복붙 + 엑셀 첨부)
- [ ] jade: 3~4일 뒤 글 2 발행 (이후는 매주 토요일 준비되는 글을 발행)

### 2순위 — 쓰레드 메이커 스토리
- "현직 재무담당자가 매일 30분 걸리던 보고를 자동화하려고 직접 만들었다"
- 제작기·개선기 소재: 부장님 피드백으로 가격 바꾼 이야기, 베타 피드백 당일 반영 등
- 주 2~3회, 클로드에게 "쓰레드 글 써줘" 하면 문구 작성
- [ ] 쓰레드 계정 준비 후 시작

### 3순위 — 경리·회계 실무자 커뮤니티
- 네이버 카페: "경리 실무", "회계 실무자" 검색해 가입
- 오픈카톡: "경리", "세무회계" 검색
- ⚠️ 바로 광고 글 올리면 강퇴 위험 — 먼저 질문에 답하며 활동 후, "제가 만들었는데 베타 테스터 찾습니다"로 정직하게
- [ ] 카페 1~2곳 가입 후 눈팅·활동부터
