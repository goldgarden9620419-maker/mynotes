# 릴스 7편 기획 - 「보고서 2시간 → 54초」 (손 실사 + 결과 먼저)

- 작성일: 2026-10-16 · 상태: 📝 기획안 (jade 확인 대기)
- 근거 (6편까지의 데이터로 만든 공식)
  1. **첫 장면 = 사람(손)** → 6편 조회 105 vs 같은 시기 웹 화면 시작 5편 2 (배포 회복)
  2. **첫 자막 = 숫자 대비** → 1·3편 건너뛰기 65~67% vs 6편 문장형 훅 80.2%
  3. **3초 안에 결과 먼저** → 6편 평균 시청 6초(과정 시작 전 이탈) → 완성 화면을 맨 앞으로
  4. **행동 유도는 하나만(저장)** → 6편 연속 반응 0, 문구를 줄여 시험
- 시험 변수: 6편 대비 **훅 문장(숫자 대비) + 결과 먼저 구성**. 첫 장면 사람은 유지
- 크레딧 0 · AI 레이블 OFF · 게시: 인스타 앱 + 앱 음악(「다음」 전 곡 이름 확인) + 페이스북 동시 공유

## 소재

- ⚠️ 중복 판정 방지: 5편과 **첫 장면·순서·길이·자막을 전부 새로** 편집 (결과 먼저 → 과정 역순 설명). 손 장면은 **새로 촬영**(6편 손 영상 재사용 금지)
- 훅 숫자 "2시간": 1편에서 쓴 jade 실제 경험(재무보고서 정리 2시간) — **jade 재확인 필요**
