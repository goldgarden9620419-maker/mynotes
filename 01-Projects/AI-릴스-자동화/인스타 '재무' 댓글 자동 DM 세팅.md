# 인스타 '재무' 댓글 자동 DM 세팅

- 작성일: 2026-10-07
- 관련: [[인스타 릴스 자동 게시 세팅 (Instagram API)]] · [[릴스 원고 재료 - 내 경험과 숫자]]

## 결론
**Meta Business Suite의 무료 기본 기능 "댓글에 메시지로 답장(Comment to Message)"**으로 설정한다. 하루보고 페이지 ↔ @kim_jade0419 연결이 끝나 있어서 바로 쓸 수 있다.

## 왜 직접 만든 API가 아니라 이것인가
| 방법 | 가능 여부 | 이유 |
|---|---|---|
| 내 앱(harubogo-reels) Private Replies API | ❌ 지금은 불가 | Standard Access는 **앱 역할이 있는 사람**에게만 동작, 댓글 웹훅도 Advanced Access 필요 → 앱 심사(개인정보처리방침·시연 영상 등, 수 주) |
| ManyChat 등 외부 도구 | ⭕ 가능 | 2026-03부터 무료는 연락처 25명까지, 이후 월 $15~ |
| **Meta Business Suite 기본 자동화** | ✅ **추천** | 무료, Meta 공식, 키워드 최대 5개 |

## 설정 순서 (PC, 10분)
1. https://business.facebook.com 접속 → 왼쪽 위 계정이 **하루보고**인지 확인
2. 왼쪽 메뉴 **받은 메시지함(Inbox)** → 위쪽 **자동화(Automations)**
3. **댓글에 메시지로 답장** (*Comment to message*) → **만들기**
4. 설정
   - 플랫폼: **Instagram** (@kim_jade0419)
   - 게시물: **특정 게시물** → 1편 릴스 선택 (또는 "모든 게시물"로 두면 이후 릴스에도 적용)
   - 키워드: `재무`, `'재무'`, `재무요`, `재무!`, `재무 부탁드려요` (최대 5개, 정확히 일치해야 하므로 변형 포함)
   - 공개 답글(선택): `DM 보내드렸어요 📩 메시지함 확인해주세요!`
   - DM 내용: 아래 문구
5. **저장 / 켜기** → 다른 계정(가족·지인)으로 1편 릴스에 `재무` 댓글을 달아 테스트

## DM 문구 (복붙)
```
안녕하세요! 댓글 남겨주셔서 감사해요 😊
말씀드린 업무일지 양식 보내드려요 👇
https://harubogo.vercel.app/templates?utm_source=instagram&utm_medium=dm

양식에 하루 업무를 적어서 같은 페이지에서 하루보고로 올리시면 재무보고서가 바로 나와요.
가입하시면 매월 3건까지 무료로 써보실 수 있어요.

혹시 지금 매주 보고서 정리에 시간이 제일 많이 드는 업무가 뭐예요?
```

## 주의
- 데스크톱 Meta Business Suite에서만 설정 가능
- 키워드는 **정확히 일치**해야 발송 → 변형 키워드 포함
- 댓글 단 사람이 나를 팔로우하지 않으면 DM이 **메시지 요청함**으로 감 (정상)
- 상대가 답장하면 24시간 안에 이어서 대화 가능

## ✅ 가동 기록
- **2026-10-07 설정 완료·켜짐** — Meta Business Suite → 받은 메시지함 → 자동화 → 「메시지에 댓글 달기」(= Comment to message)
  - 이름: 재무 댓글 → 양식 DM / 채널: Instagram(+Messenger) / 게시물: 전체(선택 칸 없음)
  - 키워드: `재무` `양식` `링크` (조건이 "포함된 댓글"이라 변형 키워드 불필요)
  - 공개 답글: "DM 보내드렸어요 📩 메시지함 확인해주세요!" / DM: 위 문구(utm_medium=dm 링크)
- 테스트: 본인 계정 댓글로는 발동 안 함 → 지인 계정으로 1편 릴스에 `재무` 댓글 → 1~15분 내 DM 확인
- 성과 집계: 사이트 방문 통계에서 utm_medium=dm(댓글 DM) vs utm_medium=bio(프로필 링크) 비교
- ✅ **2026-10-07 지인 계정 테스트 통과** — '재무' 댓글 → 양식 DM 자동 도착 확인. 실사용 가동 중
