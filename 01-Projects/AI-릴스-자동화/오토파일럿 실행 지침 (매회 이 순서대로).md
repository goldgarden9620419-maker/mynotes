## 3. 제작
- **첫 장면(0~2초) = 사람 실사**: ① 무료 상업 이용 영상 소스(Pexels·Pixabay·Mixkit 등 출처 표기 불필요 라이선스)에서 손·책상·노트북 장면 mp4 직접 받기 → ② 안 되면 Higgsfield로 3~4초 영상 생성(잔액 확인, 40크레딧 이하) + **이 경우 AI 라벨 ON**
- **화면 녹화**: Higgsfield 샌드박스 Playwright(헤드리스 Chromium)로 harubogo.vercel.app 녹화, 세로 1080×1920(모바일 뷰포트) 또는 데스크톱 녹화 후 크롭. **게스트 모드(가입 없이 체험하기) + 가상 데이터만**. 가상 파일은 `촬영용/` 폴더 것 사용·필요시 새로 만들기(가상 거래처, 합계 검증)
  - 게스트 1건 제한 → 브라우저 컨텍스트를 새로 열면 새 게스트
  - 실측 시간은 녹화에서 잰 값만 자막에 사용
- **첫 프레임 규칙 (7편 데이터: 평균 2초 이탈)**: 밝은 장면 선택(어두운 실사 금지) · 훅 자막은 화면 위쪽 1/3에 2줄, 핵심 숫자는 노란색·화면 폭 80% 크기 · 0~1초 안에 결과 화면(완성된 보고서/일정)을 화면 아래 절반에 겹쳐 미리 보여주기
- **편집 공식**: 20~28초 · 0~2초 숫자 대비 훅(사람 실사 위 큰 자막) → 2~5초 **결과 먼저** → 과정 빨리감기(①②③) → 끝 "💾 저장해두세요" 하나
- 음악: 상업 이용 가능한 무료 음원만, 낮게. 확보 못 하면 무음(+완성 순간 짧은 효과음). 합성 패드음 금지
- **자막 금지어**: '결과 먼저', '훅', 'CTA', '①②③ 단계명' 같은 **지침 속 구성 이름을 화면 자막으로 쓰지 않기** (10/28 법인카드 편에 '결과 먼저'가 제목으로 노출됨). 자막은 시청자에게 하는 말로만
- **검수(필수)**: 프레임 6~10장 뽑아 직접 보기 — 이메일·실명·실제 회사명·실제 숫자 노출 없음, 글자 깨짐(이모지 금지) 없음, 자막 오탈자 없음

## 4. 게시
- `media_upload` → 같은 명령에서 `curl PUT`(헤더 `Content-Type: video/mp4`, `If-None-Match: *`) → 200이면 `media_confirm`
- `posts/YYYY-MM-DD-epN.json` 작성 (title, video_url, is_ai_generated, share_to_feed true, thumb_offset_ms 500, caption — 짧게, "(화면 속 숫자는 촬영용 가상 데이터예요)" 포함, 해시태그 5개)
- `IG_PROXY_AUTH=1 python3 .claude/skills/instagram-auto-post/scripts/ig_publish.py --post <파일> --dry-run` → 통과하면 `--dry-run` 없이 **한 번만** 게시
- 게시 실패 시 재시도는 1번까지. **삭제·재업로드 절대 금지**

## 5. 기록·저장

- [[인스타 릴스 자동 게시 세팅 (Instagram API)]] 게시 기록에 한 줄

- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

- **녹화 크롭 필수**: Playwright recordVideo는 viewport보다 크게 지정하면 왼쪽 위에 붙고 나머지는 회색 → 편집 때 `crop=W:H:0:0` 후 확대. 검수 프레임은 540폭 이상으로 보고 회색 여백·화면 밖 잘림이 없는지 확인 (10/28 9편 결함)
