## jade가 할 일
**A. 촬영 계정 만들기 (PC 또는 폰, 2분)**
1. 시크릿 창에서 `harubogo.vercel.app/login` → **회원가입**
2. 이메일 `goldgarden9620419+demo@gmail.com` · 새 비밀번호 → 가입 (인증 메일이 오면 같은 Gmail에서 클릭)

**B. 실사 촬영 (폰 카메라, 1분)**
1. 책상 위에 커피 컵 + 폰을 놓기 (회사 서류·모니터 화면이 안 나오게)
2. **다른 폰/태블릿이 없으면**: 폰을 세워 두고 동영상 촬영 시작 → 손으로 컵을 들었다 놓기 → 5초 찍고 정지 (손이 폰을 집는 장면은 생략 가능)
3. 세로로, 5~8초

**C. 폰 화면 녹화 (1분)**
1. 폰 브라우저에서 촬영 계정으로 로그인 → **하루쉼표** 화면
2. 상단 빠른 설정 → **화면 녹화** 시작
3. 가상 문장 1→2→3 입력(복사·붙여넣기 OK) → 🌙 마무리 → 「일정 보드 보기」 → 3초 머무르기 → 정지
4. 영상 2개(실사 + 화면 녹화)를 구글 드라이브에 올리고 이름 알려주기 → Claude 편집 → 폰에 저장 → 앱에서 음악 넣어 게시
