# 온라인 건물주 — 나만의 SaaS 실행 로드맵

> 작성일: 2026-08-31
> 기반: [[복붙으로 시작하는 온라인 건물주 - 책 분석 및 핵심 정리]] · [[바이브 코딩 SaaS 실행 체크리스트 (169가지)]]
> 목표: 책의 공식(아이디어→BM→PRD→세팅→제작→배포→런칭)을 **내 상황에 맞게** 변형해서 첫 구독형 SaaS 런칭

## 1. 나는 책의 독자보다 이미 앞서 있다

책은 "코딩 못 하는 완전 초보"를 기준으로 쓰였지만, 내 현재 상태는:

| 책의 전제 | 나의 현재 |
|---|---|
| AI 도구 처음 씀 | **클로드 코드를 매일 사용** (스킬·MCP·자동화 파이프라인 구축 경험) |
| 웹사이트 만들어본 적 없음 | 사주 웹사이트, 숨은맛집찾기, 수능잼 사이트 등 **이미 여러 개 제작** |
| GitHub 모름 | **매일 git push로 노트·사이트 운영 중** |
| 아이디어 없음 | 재무보고 자동화, 콘텐츠 파이프라인 등 **실제로 돌아가는 자동화 자산 보유** |

→ 결론: 책의 1편(개념)과 2편 상당 부분(Cursor 설치, Git 개념)은 건너뛰어도 된다. **내가 실제로 새로 해야 하는 것은 ① 아이디어 검증 ② Supabase(DB)+회원/결제 ③ 토스페이먼츠 ④ 런칭**이다.

## 2. 도구 치환표 (책 추천 → 나의 스택)

| 책 추천 | 나의 대체 | 메모 |
|---|---|---|
| Cursor | **클로드 코드** (이미 사용 중) | PRD.md 만들고 "Supabase MCP로 DB 만들고 앱 완성해줘" 동일하게 작동 |
| BON.AI Business/PRD 버튼 | **클로드에게 부록 1 프롬프트 직접 입력** | 채팅에서 "BM 설계서 만들어줘" 한마디면 됨. BON.AI는 선택사항(코드 bestbonai 20%↓) |
| Supabase | 그대로 사용 (신규 가입 필요) | 서울 리전, MCP 연결 |
| Vercel | 그대로 사용 | 기존 사이트 배포 경험 활용 |
| 토스페이먼츠 | 그대로 사용 (신규 신청 필요) | ⚠️ 사업자등록증 필요, 승인 1~2주, **정기결제 별도 신청** |

## 3. 내 강점 기반 SaaS 아이디어 후보 3개

### 후보 A — 중소기업 업무일지 → 재무보고 자동 변환 SaaS ⭐ 추천
- **한 줄**: "경리·재무 담당자가 매일 쓰는 업무일지(PDF/엑셀)를 올리면 대표 보고용 재무보고서가 1분 만에 나오는 서비스"
- **Why Me**: 에이팜건강에서 이미 실전으로 구축·운영 중 (업무일지→재무보고, 매입매출장→경영대시보드, 자금수지 자동화). 남들은 상상으로 만들지만 나는 **실사용 검증된 로직**이 있다
- **검증 포인트**: 크몽에서 "엑셀 자동화/재무 보고" 건당 가격 확인 → 월 구독 환산
- **BM 초안**: 무료 월 3건 / 유료 월 29,000원 무제한 + 대시보드 + 월간 리포트

### 후보 B — 1인 부업러용 콘텐츠 풀세트 생성 SaaS
- **한 줄**: "주제 하나 넣으면 블로그 글 + 쓰레드 + 썸네일 문구까지 한 번에 나오는 서비스"
- **Why Me**: 이미 나 자신이 쓰는 파이프라인(스킬)이 있음. 내가 첫 사용자
- **리스크**: 경쟁 치열 (뤼튼 등 대형 서비스 존재) — 차별점은 '한국형 수익화(애드센스 승인·네이버 상위노출) 특화'

### 후보 C — 기존 사이트의 구독화 (수능잼 등)
- **한 줄**: 이미 운영 중인 사이트에 회원가입+월 구독(프리미엄 문제/기록 기능)을 붙여 SaaS로 전환
- **장점**: 신규 제작 없이 책의 3편(회원·결제·배포)만 연습 가능 — **가장 빠른 실습 코스**

> 추천 진행: **C로 결제 연동을 연습**하면서(1~2주), **A를 본 프로젝트**로 검증·설계 병행.

## 4. 4주 실행 플랜

### 1주차 — 검증 + BM (체크리스트 1편 CH2 + 부록1)
- [ ] 크몽 '디지털·자동화' 상위 10개 + 재무/엑셀 자동화 가격대 조사
- [ ] 숨고에서 '재무/정리/자동화' 반복 요청 확인
- [ ] 검증 질문 3개에 답하기 (빈도/현재 해결법/불편)
- [ ] 최종 아이디어 한 줄 확정: "OO한 사람이 OO 문제를 자동화하는 앱"
- [ ] 부록 1 프롬프트 [ ] 채워서 클로드에게 입력 → BM 설계서 6개 섹션 받기
- [ ] **토스페이먼츠 이용 신청 + 정기결제 별도 신청 (승인 1~2주라 지금 바로!)**

### 2주차 — PRD + 인프라 세팅 (체크리스트 1편 CH3 + 2편 CH4)
- [ ] BM 전체를 클로드에게 주고 PRD 생성 (기능명세+ERD+TRD+화면구성+P0/P1/P2)
- [ ] 추상적이면 추가 질문: "DB 스키마 테이블별로" / "사용자 플로우 단계별로"
- [ ] PRD.md 파일로 저장, MVP 기능 3개로 압축
- [ ] Supabase 가입 → 서울 리전 프로젝트 생성 → MCP 연결
- [ ] GitHub 새 저장소(서비스명) + Vercel 연동

### 3주차 — MVP 제작 (체크리스트 3편 STEP 1~4)
- [ ] 클로드 코드에 지시: "PRD.md 보고, Supabase MCP 통해 DB 만들고, 앱 완성해줘"
- [ ] 로컬 확인(npm run dev) → 회원가입/로그인 → Supabase 테이블에 데이터 확인
- [ ] MVP 3기능 작동 확인
- [ ] 토스 키 3종 env.local 등록 → 요금제 페이지 → **정기결제(구독형)** 테스트

### 4주차 — 배포 + 런칭 (체크리스트 3편 STEP 5~8 + 최종 점검)
- [ ] Vercel 배포 → 환경변수 5종 등록 → **Redeploy**
- [ ] 커스텀 도메인 구매·연결
- [ ] 최종 점검 19항목 (E2E, 모바일, **라이브 키 교체**, 3초 로딩, 지인 테스트)
- [ ] 첫 고객 100명 채널 확정 — 나의 채널: 쓰레드 + 블로그 + 오픈카톡 커뮤니티 (광고비 0원 전략과 정확히 일치)

## 5. 다음 액션 (오늘 할 일)

1. 후보 A/B/C 중 본 프로젝트 확정 (추천: C 연습 + A 본선)
2. 토스페이먼츠 신청 (승인 대기 시간이 가장 긴 병목)
3. 확정되면 클로드에게: **"부록 1 프롬프트로 [아이디어] BM 설계서 만들어줘"** 라고 요청 → 1주차 시작
