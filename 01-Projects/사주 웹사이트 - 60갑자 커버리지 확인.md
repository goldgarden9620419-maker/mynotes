# 사주 웹사이트 - 60갑자 커버리지 확인

> 유명인 DB의 일주(日柱)가 전체 60갑자 중 몇 개를 커버하는지 계산

## ✅ 업데이트 (2026-08-06): 161명 → **206명** (45명 추가)
갑자당 2명뿐이던 19개 일주를 우선 보강해, 2명인 갑자가 19개 → 5개로 줄었습니다
(3명 31개, 4명 19개, 5명 3개, 6명 2개, 2명 5개). 동시에 과학자·고전 작가·화가·
팝스타/K팝 아이돌·스포츠·기업가·인도주의자·패션 디자이너·영화배우·무용수·
프로게이머 등 분야 다양성도 넓혔습니다.
추가로 감사 중 기존 데이터 오류를 하나 발견해 수정: "김지수(블랙핑크 제니)" 항목이
이름과 활동명이 뒤바뀐 오류였음(일주 壬子는 제니의 실제 생일 기준으로 정확했지만
이름 필드엔 지수의 실명이 들어가 있었음) → "김제니(블랙핑크 제니)"로 정정하고,
지수 본인도 별도 인물(甲午)로 신규 추가했습니다.
전체 206명 상세 데이터는 `01-Projects/사주 웹사이트 - 프로토타입 코드/celebrities.json` 참고.

## 이전 업데이트 (2026-08-04): 100% 커버 → 121명 → 116명 → 161명
1차로 미커버 38개 갑자에 해당하는 인물을 추가해 **27명 → 65명, 60갑자 100% 커버**를 달성했고,
갑자당 최소 2명을 목표로 56명을 더해 **65명 → 121명**으로 확장했습니다.
이후 톤 검토 대상이었던 정치인 4명·이재용을 제거해 116명으로 정리했다가,
甲子·乙丑·己巳·甲戌·辛巳를 다시 채우고 나머지 갑자도 3명까지 보강해 최종 **161명**이 됐습니다.
- 60갑자 커버리지 100% 유지, **전 갑자 최소 2명 확보** (2명 19개, 3명 41개 갑자)
- 전체 161명 상세 데이터는 `01-Projects/사주 웹사이트 - 프로토타입 코드/celebrities.json` 및 [[사주 웹사이트 - 유명인 일주·오행 태깅]] 참고

아래는 이전(27명 시점) 분석 기록입니다.

## 요약 (당시 기준)
- **전체 60갑자 중 22개 커버 (36.7%), 38개 미커버 (63.3%)**
- 27명인데 22개만 커버되는 이유: 일주가 겹치는 인물이 여럿 있음 (아래 참고)
- 결론: **당시 DB만으로 "일주 완전 일치" 매칭을 하면 방문자 10명 중 6명 이상은 정확히 일치하는 유명인이 없음** → 매칭 전략 재설계 필요 (→ 정확일치 우선 + 오행 폴백 구조로 해결, 이후 DB 확장으로 폴백 의존도 자체를 낮춤)

## 시사점 & 매칭 전략 제안

1. **1차 매칭(정확 일치)**: 사용자 일주가 22개 커버 목록에 있으면 → 해당 유명인 그대로 매칭 (중복 시 여러 명 중 랜덤/전체 노출)
2. **2차 매칭(폴백)**: 일주가 미커버 38개 중 하나면 → **오행(木火土金水) 기준으로 가장 가까운 유명인**을 보여주는 구조로 설계 (오행별 카피는 이미 작성 완료, `01-Projects/사주 웹사이트 - 오행별 설명 카피.md` 참고)
3. 이렇게 하면 "완전 일치 유명인"이 없어도 사용자에게 항상 결과를 줄 수 있어 이탈을 막을 수 있음
4. 장기적으로는 DB를 60갑자 전체(최소 60명, 이상적으로는 갑자당 2~3명씩 120~180명) 규모로 확장해 "정확 일치" 비율을 높이는 게 목표
