# 사주 웹사이트 - 매칭 로직 프로토타입

## 개요
- **입력**: 사용자 생년월일(양력)
- **1차**: 만세력 라이브러리(`lunar_python`)로 일주(日柱) 계산 → DB에 정확히 일치하는 유명인 있으면 매칭
- **2차 폴백**: 정확 일치가 없으면 일간 오행(木火土金水) 기준으로 매칭
  - **생년월일 해시 기반 시드 고정** 적용 → 같은 사람이 같은 날짜로 여러 번 조회해도 항상 같은 유명인이 나옴 (일반 `random.sample`은 매번 결과가 달라져서 신뢰도 문제가 있었음, 이번에 수정)
- DB는 지금까지 만든 27명 + 오행별 카피를 그대로 코드에 반영

## 실행 환경
```bash
pip install lunar_python
```

OHANG_INDEX = {}
for c in CELEBRITY_DB:
    OHANG_INDEX.setdefault(c.ohang, []).append(c)


def get_ilju(year: int, month: int, day: int) -> str:
    solar = Solar.fromYmd(year, month, day)
    return solar.getLunar().getEightChar().getDay()


def match(year: int, month: int, day: int, max_results: int = 3) -> dict:
    ilju = get_ilju(year, month, day)
    ohang = STEM_TO_OHANG[ilju[0]]
    exact = ILJU_INDEX.get(ilju, [])

    if exact:
        return {
            "match_type": "exact",
            "ilju": ilju,
            "ohang": ohang,
            "celebrities": exact[:max_results],
            "ohang_copy": OHANG_COPY[ohang],
        }

    pool = OHANG_INDEX.get(ohang, [])
    # 생년월일 기반 고정 시드 -> 같은 입력은 항상 같은 결과
    seed_str = f"{year:04d}-{month:02d}-{day:02d}"
    seed = int(hashlib.sha256(seed_str.encode()).hexdigest(), 16)
    rng = random.Random(seed)
    picks = rng.sample(pool, k=min(max_results, len(pool)))
    return {
        "match_type": "fallback_ohang",
        "ilju": ilju,
        "ohang": ohang,
        "celebrities": picks,
        "ohang_copy": OHANG_COPY[ohang],
    }

## 실제 실행 결과 (검증용)

```
입력: 1955-02-24  ->  일주: 丙辰 (火), 매칭유형: exact
  오행 타입: 세상을 밝히는 열정가 - 보는 사람까지 뜨겁게 만드는 타고난 표현가
  - 스티브 잡스 (丙辰) : Stay hungry, stay foolish

입력: 1990-03-15  ->  일주: 己卯 (土), 매칭유형: fallback_ohang
  오행 타입: 모두를 품는 중심축 - 흔들리는 사람들도 믿고 기댈 수 있는 든든한 중심
  - 마크 저커버그 (戊申) / 마이클 잭슨 (戊寅) / 반기문 (戊申)

입력: 1988-11-02  ->  일주: 辛酉 (金), 매칭유형: fallback_ohang
  오행 타입: 원칙을 지키는 결단가
  - 마이클 조던 (辛卯) / 아놀드 슈워제네거 (庚戌) / 제프 베이조스 (庚申)

입력: 2000-01-01  ->  일주: 戊午 (土), 매칭유형: fallback_ohang
  - 반기문 (戊申) / 박세리 (戊子) / 마이클 잭슨 (戊寅)

입력: 1975-06-21  ->  일주: 戊戌 (土), 매칭유형: fallback_ohang
  - 반기문 (戊申) / 마크 저커버그 (戊申) / 마이클 잭슨 (戊寅)

=== 재현성 테스트 (1990-03-15, 3회 반복) ===
  [1회차] ['마크 저커버그', '마이클 잭슨', '반기문']
  [2회차] ['마크 저커버그', '마이클 잭슨', '반기문']
  [3회차] ['마크 저커버그', '마이클 잭슨', '반기문']
```

**검증**:
1. 스티브 잡스 본인 생일(1955.02.24)을 입력하면 정확 매칭으로 스티브 잡스 본인이 나오는 것을 확인 → 계산 로직 정합성 확인 완료
2. 나머지 임의 날짜는 예상대로 폴백(오행) 매칭으로 처리됨(현재 DB가 60갑자의 37%만 커버하므로)
3. **같은 날짜(1990-03-15)를 3번 반복 조회해도 항상 동일한 3명이 나옴** → 시드 고정 정상 동작 확인
