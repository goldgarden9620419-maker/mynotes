# (주)에이팜건강 주간 자금계획 자동화 — 프로젝트 개요

작성일: 2026-09-18

## 무엇을 만들었나

팀별 주간 지출계획 + 3개 은행(농협·우리·국민) 거래내역을
매주 월요일 09:10에 자동으로 취합·대조·예측해서
`주간자금계획_*.xlsx`(11개 시트) / `대표보고 PDF` / `확인필요_*.xlsx` 를
만들어 주는 Windows 상주 프로그램.

- 작업 스케줄러 없이 내부 APScheduler + 트레이 상주 + 시작프로그램 등록
- PC가 꺼져 있던 주도 켜자마자 자동 보완 실행 (state.json ISO 주차 기준)
- 요청ID(팀코드-등록일-일련번호)로 변경·취소 추적, 대외비는 분류·총액만 노출

## 폴더 구성

- `cashflow_automation/` — 전체 소스(모듈 19개), tests 41개, docs 5종,
  build/설치 bat, config.yaml, requirements.txt
- `양식/` — 팀별 제출양식 6종 + 경영지원 대외비 양식 + 자금계획 기준파일
  (카드결제기준·주간조정 시트 포함) — `tools/make_templates.py`로 재생성 가능
