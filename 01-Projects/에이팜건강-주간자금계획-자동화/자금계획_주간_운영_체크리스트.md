# 주간 자금계획 운영 체크리스트

> 프린트해서 보면서 진행하세요. 자동화가 계산을 다 하고, 사람은 **파일 넣기와 확인**만 합니다.
> (2026-10-11 기준 · 실행시간: 주간대조 금 17:00 / 자금계획 월 10:30 자동)

---

## A. 금요일 오후 — 지난주 마감 (주간대조)

- [ ] **A1. 은행 3사 파일 다운로드 → 폴더에 넣기** (17:00 전까지)
  - 국민·농협·우리 거래내역을 받아 `자금계획_자동화/03_은행거래내역/` 아래 각 은행 폴더에 저장
  - **왜**: 주간대조의 재료. 파일이 옛날 것이면 "출금 0원"으로 잡혀 차이가 전부 허수로 나옵니다 (10/11 실제 사례)
- [ ] **A2. 17:00 주간대조 자동 실행 — 기다리기만**
  - (수동으로 돌리려면 바탕화면 '자금계획 주간 대조' 클릭)
  - **무슨 일이 되나**: 지난주 계획 vs 실제 출금을 계좌별로 비교 → `06_확인필요/주간대조_*.xlsx` 생성
- [ ] **A3. 주간대조 '차이내역' 시트 확인** (5분)
  - **미집행(주황)** ← 제일 중요: 다음 주에 나갈 돈이면 **이월**(취합에 반영), 안 나갈 돈이면 **취소** 결정
  - **일부지급(노랑)**: 남은 금액을 다음 주 취합에 이월
  - **계획없는출금(붉은)**: 눈으로만 — 월요일 확인필요에서 드롭다운으로 분류하면 됩니다
  - **지급일차이**: 금액이 맞으면 조치 불필요
  - 끝나면 안내 시트 **'확인 완료' ▼ '예'** 저장 (기록용)

## B. 주말 ~ 월요일 10:30 전 — 재료 준비

- [ ] **B1. 취합 지출계획 파일 갱신** (`02_경영지원_대외비/지출계획_날짜.xlsx`)
  - A3에서 정한 이월 건 + 이번 주 신규 지출 반영
  - **주의**: 같은 지급 건은 새로 등록하지 말고 **기존 요청ID의 '변경'으로 수정** (중복 등록하면 합계가 2배로 잡힘)
- [ ] **B2. 일반팀 지출계획 6종 최신 확인** (`01_일반팀_지출계획/`)
  - 지출 없는 팀은 그대로 둬도 됨 (확인필요에 "항목 없음 — 무시"로만 표시)
- [ ] **B3. 월요일 아침 최신 은행 파일 넣기**
  - 금요일 이후(금~일) 거래까지 반영하려면 월요일 아침 파일이 가장 정확
  - **마감**: 10:30. 늦어도 프로그램이 **12:30까지 10분마다 재시도**하니 여유 있음

## C. 월요일 10:30 — 자금계획 자동 실행 (확인 타이밍!)

- [ ] **C1. 자동 실행 → 확인필요 파일이 화면에 자동으로 열림**
  - **무슨 일이 되나**: 취합+팀 계획과 은행 거래를 대조하고 4주/13주 자금흐름을 계산. **단, 결과 파일은 아직 안 만들고 사람 확인을 기다림**
- [ ] **C2. 확인필요 파일 검토** (5~10분)
  - **주황색 행(새 항목)** 위주로 보기
  - 노란 **처리 칸은 클릭하면 안내가 뜨고 ▼로 선택**: 계획 없는 출금 → 분류 선택(한 번 고르면 다음부터 자동) / 당일 차이 → 유지·보류 / 정기지출누락 시트 → 계획에 반영 여부
  - 모르는 항목은 **비워 두면 됨** (다음 실행 때 다시 올라옴)
- [ ] **C3. 안내 시트 '확인 완료' ▼ '예' → 저장**
  - 이 저장이 승인 버튼입니다. 곧바로 `05_결과/주간자금계획_*.xlsx` 생성
- [ ] **C4. 결과 확인**
  - **요약 시트**: 현재 잔액·통계 / **대표보고 시트**: 그대로 A4 인쇄해 보고
  - **4주 최저 예상잔액**과 **자금부족 예상일**이 있는지 확인 — 수정은 경영보고 시트 노란 칸에서

## D. 예외 상황 — 이럴 땐 이렇게

| 상황 | 대처 |
|---|---|
| 월요일에 PC를 못 켰다 | 다음에 켜면 밀린 주를 자동 보완 실행. 클라우드(Claude)도 월 11:29에 점검해서 PC가 못 돌았으면 대신 돌려 결과를 채팅으로 보냄 |
| 파일을 늦게 넣었다 | 12:30까지 10분마다 자동 재시도 — 넣는 순간 이어서 진행 |
| Excel '복구' 창 등 오류 | 화면 캡처해서 Claude에게 — 바로 수정 |
| 확인할 시간이 없다 | 확인필요를 '예' 안 하면 결과가 안 만들어진 채 대기. 나중에 열어 '예' 하고 저장하면 됨 |
