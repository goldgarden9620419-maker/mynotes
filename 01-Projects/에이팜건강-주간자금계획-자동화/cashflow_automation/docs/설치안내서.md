# 설치 안내서

## 1. 준비물

- Windows 10/11 PC (자금 담당자 PC)
- Python 3.11 이상 (빌드용 PC에만 필요, https://python.org)
  - 설치 시 **"Add python.exe to PATH"** 반드시 체크
- 이 저장소의 `cashflow_automation` 폴더 전체와 `양식` 폴더

## 2. EXE 빌드 (빌드용 PC에서 1회)

1. `cashflow_automation` 폴더를 임의 위치에 복사한다.
2. `build_exe.bat` 을 더블클릭한다.
   - 라이브러리 설치 → pytest 테스트 → PyInstaller 빌드가 자동 진행된다.
   - 테스트가 실패하면 빌드가 중단된다(정상 동작 보증 장치).
3. 완료되면 `dist\cashflow_automation.exe` 가 생긴다.

## 3. 운영 PC 폴더 만들기

1. 운영 PC에 기준 폴더를 만든다. 예: `D:\자금계획_자동화`
   (한글·공백 경로 모두 가능. OneDrive 아래도 가능하나 동기화 지연을
   고려해 `config.yaml`의 `initial_wait_seconds`를 늘릴 수 있다.)
2. 그 안에 `00_프로그램` 폴더를 만들고 다음을 복사한다.
   - `dist\cashflow_automation.exe`
   - `config.yaml` (없으면 첫 실행 때 기본값으로 자동 생성)
   - `install_startup.bat`, `uninstall_startup.bat`
3. `cashflow_automation.exe` 를 한 번 실행한다.
   → `01_일반팀_지출계획` ~ `99_지난자료` 폴더가 자동 생성되고
   트레이(작업표시줄 오른쪽 아래)에 파란 아이콘이 나타난다.

## 4. 양식 배치

1. `양식` 폴더의 팀별 파일 6개를 `01_일반팀_지출계획\` 에 복사한다.
2. `경영지원팀_대외비_지출계획.xlsx` 를 `02_경영지원_대외비\` 에 복사한다.
3. `에이팜건강_자금계획_기준파일.xlsx` 를 `04_기준파일\` 에 복사한다.
4. **중요:** 기준파일의 `카드결제기준` 시트를 열어 우리카드·국민카드의
   실제 결제일과 이용기간을 회사 카드 약정에 맞게 수정한다.
   - 이용기간은 `전월 13일`, `당월 12일`, `전월 말일` 형식으로 입력
5. 팀 양식의 `지출계획` 시트는 보호되어 있다(요청ID 열 잠금).
   해제 암호: `apharm` (양식 수정이 필요한 관리자만 사용)

## 5. 시작프로그램 등록

1. `00_프로그램\install_startup.bat` 을 더블클릭한다.
2. "시작프로그램 등록 완료" 메시지를 확인한다.
3. 트레이 아이콘 → "이번 주 실행상태 확인" 에서
   `시작프로그램 등록: 예` 로 표시되는지 확인한다.
4. 해제하려면 `uninstall_startup.bat` 을 실행한다.

## 6. 설치 확인 (첫 주 전 리허설)

1. 팀 양식 1개에 테스트 데이터를 한 줄 입력하고,
   각 은행 폴더에 거래내역 파일을 넣는다.
2. 트레이 메뉴 → **지금 실행** 을 누른다.
3. `05_결과` 폴더에 다음 3개 파일이 생기면 정상이다.
   - `주간자금계획_YYYYMMDD_HHMM.xlsx`
   - `주간자금계획_대표보고_YYYYMMDD_HHMM.pdf`
   - `확인필요_YYYYMMDD_HHMM.xlsx`
4. 리허설이 끝나면 테스트 데이터를 지우고, `00_프로그램\state.json` 을
   삭제(또는 초기 state.json으로 교체)하면 상태가 초기화된다.

## 7. 설정 변경

- 실행 시각·폴더 경로·반영률·최소잔액: `00_프로그램\config.yaml`
- 은행 자동분류 키워드: `00_프로그램\classify_rules.json` (첫 실행 때 생성)
- 변경 후에는 트레이 메뉴 → 프로그램 종료 후 다시 실행해야 반영된다.
