## 이 환경에서 검증하지 못한 것 (Windows 실기기 확인 필요)

- PyInstaller EXE 빌드(`build_exe.bat`)와 시작프로그램 등록 bat —
  Windows 전용이라 Linux 테스트 환경에서는 실행 불가. 정상 작동을
  보고하지 않으며, 설치안내서 6장의 리허설 절차로 확인해야 한다.
- 시스템 트레이(pystray) 실제 표시·알림 — 코드 작성 및 임포트 구조는
  검증했으나 GUI 없는 환경이라 화면 표시는 미검증.
- 은행 3사의 실제 다운로드 파일 — 대표적인 열 이름으로 자동 인식하도록
  구현했으나, 실제 파일로 첫 주에 확인필요 목록을 반드시 검토할 것.
