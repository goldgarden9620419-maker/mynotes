# 매주 운영 안내서

## 주간 일정

| 요일 | 할 일 | 담당 |
|---|---|---|
| 금요일 | 다음 주 지출계획 양식 작성 요청(각 팀) | 자금 담당자 |
| ~월요일 08:50 | 팀 파일 7개를 지정 폴더에 저장 | 각 팀/자금 담당자 |
| ~월요일 08:50 | 3개 은행에서 최근 14일 거래내역 다운로드 후 은행별 폴더에 저장 | 자금 담당자 |
| 월요일 09:10 | 프로그램 자동 실행 (사람 조작 불필요) | 자동 |
| 월요일 오전 | 확인필요 목록 처리, 대표 보고 | 자금 담당자 |

자료를 자금계획 파일에 직접 복사·붙여넣을 필요가 없습니다.
파일을 폴더에 저장하는 것까지만 하면 됩니다.

## 파일 저장 규칙

- 일반팀: `01_일반팀_지출계획\{팀명}_주간지출계획.xlsx` — 파일명을 바꾸지 않는다.
- 경영지원: `02_경영지원_대외비\경영지원팀_대외비_지출계획.xlsx`
- 은행: `03_은행거래내역\농협|우리은행|국민은행\` 아래에
  XLS/XLSX/CSV로 저장. 파일명은 자유(같은 거래가 두 파일에 있어도
  자동으로 중복 제거된다).

## 팀 입력 규칙 (양식의 '사용안내' 시트에도 있음)

- 요청ID는 자동 생성·잠금. 일련번호는 같은 날 등록 순서대로 직접 입력.
- 내용이 바뀌면 행을 새로 만들지 말고 그 행에서 진행상태를 `변경`으로,
  취소면 `취소`로 바꾸고 최종수정일을 갱신한다.
- `확정` + `신규/변경` 건만 자금계획 합계에 반영된다.
- 법인카드는 지급예정일에 **카드 사용일**을 쓰고 카드구분을 선택한다.

## PC가 꺼져 있었던 경우

아무 것도 할 필요 없습니다. PC를 켜서 프로그램이 시작되면
약 60초 후 이번 주 완료 여부를 확인하고, 완료 기록이 없으면
요일과 무관하게 즉시 보완 실행합니다.

## 트레이 메뉴

| 메뉴 | 기능 |
|---|---|
| 상태 줄(상단 2줄) | 현재 실행상태, 다음 자동 실행 일시 |
| 지금 실행 | 이번 주 작업을 즉시 실행 |
| 이번 주 실행상태 확인 | 마지막 실행·성공 기록, 결과파일, 시작프로그램 등록 여부 |
| 누락파일 확인 | 아직 제출되지 않은 팀/은행 자료 표시 |
| 변경자료 반영 | 성공 후 입력이 바뀌었을 때 승인하고 다시 생성 |
| 결과폴더 열기 / 실행로그 열기 | 해당 폴더 열기 |
| 자동실행 일시정지 | 체크하면 자동 실행 중단(수동 실행은 가능) |
| 프로그램 종료 | 상주 종료 |

## 결과물 확인

1. `05_결과\주간자금계획_*.xlsx`
   - 요약 → 4주일별계획 → 13주주별계획 순으로 확인
   - 빨강(자금부족)·노랑(주의) 행을 우선 검토
2. `확인필요_*.xlsx` — 모든 건을 그 주 안에 처리한다.
   오류 건을 임의로 삭제하거나 0원으로 처리하지 않는다.
3. `주간자금계획_대표보고_*.pdf` — 대표 보고용 요약
4. 같은 날 여러 번 실행해도 기존 파일은 덮어쓰지 않고 `_2`, `_3`이 붙는다.

## 실행 후 자료가 바뀌었을 때

성공(SUCCESS) 후 팀/은행 파일이 변경되면 트레이 알림이 뜹니다.
- 즉시 반영하려면: 트레이 → **변경자료 반영**
- 나중에 처리하려면: 그대로 두면 된다(자동 재생성 없음)
- 무엇이 바뀌었는지 보려면: **누락파일 확인** 및 `07_실행로그`의 당일 로그

## 대외비 취급

- 경영지원 대외비 상세는 결과물에 분류·총액으로만 표시된다.
- 실행 로그에도 임직원 이름·급여 상세는 기록되지 않는다.
- `02_경영지원_대외비` 폴더 접근 권한은 경영지원 담당자로 제한할 것.
