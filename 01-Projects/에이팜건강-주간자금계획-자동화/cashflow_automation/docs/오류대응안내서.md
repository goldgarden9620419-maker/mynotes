# 오류 대응 안내서

문제가 생기면 ① 트레이 → 이번 주 실행상태 확인, ② `07_실행로그\automation_YYYYMMDD.log`
순서로 확인합니다.

## 실행상태별 대응

| 상태 | 의미 | 대응 |
|---|---|---|
| NOT_RUN | 이번 주 아직 실행 전 | 월요일 09:10을 기다리거나 "지금 실행" |
| RUNNING | 실행 중 | 잠시 대기. 30분 이상 지속되면 아래 'lock 파일' 참고 |
| SUCCESS | 정상 완료 | 조치 불필요 |
| WAITING_FILES | 필수자료 대기 | "누락파일 확인"으로 빠진 팀/은행 파일을 채우면 10분 내 자동 재실행 |
| PARTIAL | 일부 자료 누락 상태로 부분 실행됨 | 누락 자료를 채운 뒤 "변경자료 반영" |
| FAILED | 실행 실패 | 로그의 오류 메시지 확인 후 아래 증상별 대응 |
| CANCELLED | 사용자 취소 | 필요 시 "지금 실행" |

## 증상별 대응

### 1. "필수자료 대기"가 계속될 때
- 파일명이 규칙과 다르면 인식되지 않는다.
  예: `물류팀_주간지출계획.xlsx` (앞뒤 공백·(1) 복사본 표기 금지)
- 은행 폴더는 확장자(xls/xlsx/csv/txt/html)가 무엇이든 **파일 내용을
  스스로 판별**해 읽는다 (구형 XLS, HTML 표 저장본, CSV 내용의 엑셀
  확장자 파일 포함). PDF 내역서만 사용 불가.
- OneDrive 동기화 지연이면 파일이 실제로 내려왔는지(구름 아이콘 X) 확인.

### 2. "손상된 파일" / "파일 열기 실패"
- 은행 파일은 형식을 자동 판별(스타일이 깨진 xlsx도 복구 시도)하므로
  재저장이 필요 없다. 그래도 손상으로 나오면 은행 사이트에서 다시
  내려받는다.
- 팀 파일은 Excel에서 열어 "다른 이름으로 저장" → xlsx로 재저장.
- 암호 걸린 파일은 암호를 해제해서 저장한다.
- 격리된 파일은 `06_확인필요\손상파일\` 에 사유와 함께 보관된다.

### 3. "필수 열 누락" / "헤더를 찾지 못했습니다"
- 팀 파일: 열 이름·시트명(지출계획)을 양식 원본과 같게 되돌린다.
- 은행 파일: 은행 사이트에서 "거래내역 조회(엑셀저장)" 기본 형식으로
  다시 내려받는다. 열 이름을 편집하지 않는다.

### 4. 반영상태 "결제일확인필요"
- 기준파일 `카드결제기준` 시트에 해당 카드구분이 있고
  사용여부가 `사용`인지, 이용기간 형식(`전월 13일` 등)이 맞는지 확인.
- 수정 후 "변경자료 반영"을 누른다.

### 5. 대조결과 "수동확인필요" / "계획없는출금"
- 프로그램은 불확실한 건을 임의로 지급완료 처리하지 않는다.
- 확인필요 파일에서 해당 거래를 은행 내역과 직접 대조하고,
  계획에 없던 정기 지출이면 `classify_rules.json`에 키워드를 추가하면
  다음 주부터 자동 분류된다.

### 6. 30분 넘게 RUNNING / "다른 실행이 진행 중입니다"
- 비정상 종료로 lock이 남은 경우: 프로그램을 완전히 종료 후 다시 실행하면
  죽은 프로세스의 lock은 자동 제거된다.
- 그래도 반복되면 `00_프로그램\cashflow_automation.lock` 을 직접 삭제한다
  (프로그램이 꺼진 상태에서만).

### 7. PDF 한글이 깨질 때
- Windows에는 맑은고딕이 기본 설치되어 있어 정상 표시된다.
- 폰트 문제가 의심되면 `C:\Windows\Fonts\malgun.ttf` 존재를 확인한다.

### 8. 결과 파일이 안 열릴 때
- 프로그램은 저장 후 재열기 검증에 실패하면 SUCCESS로 기록하지 않는다.
- `08_백업\` 의 입력 백업으로 언제든 다시 실행할 수 있다:
  백업 zip을 풀어 원래 폴더에 넣고 "지금 실행".

### 9. 상태가 꼬였을 때 (최후 수단)
1. 트레이에서 프로그램 종료
2. `00_프로그램\state.json` 삭제 (결과·입력 파일은 삭제하지 않는다)
3. 프로그램 재실행 → 이번 주 기록이 없으므로 자동 보완 실행

### 10. 재설치
- `00_프로그램` 의 EXE만 새 버전으로 교체하면 된다.
- 데이터 폴더(01~99)는 그대로 유지된다.

## 문의 전 준비하면 좋은 것

- `07_실행로그` 의 당일 로그 파일
- 문제가 된 입력 파일 (대외비 파일 제외)
- 트레이 "이번 주 실행상태 확인" 화면 내용
