# 자동처리 순서도

## 전체 흐름

```mermaid
flowchart TD
    A[PC 켜짐 / 프로그램 시작] --> B[60초 대기\nOneDrive·네트워크 동기화]
    B --> C{이번 주\nSUCCESS 기록 있음?}
    C -- 예 --> D[대기: 입력 변경 감지만 수행]
    C -- 아니오 --> E{월요일 09:10\n지났는가?}
    E -- 아니오 --> F[예정 시각까지 대기\nAPScheduler]
    E -- 예 --> G[즉시 보완 실행]
    F -->|월 09:10| G

    G --> H{lock 파일 검사}
    H -- 실행 중 --> D
    H -- 통과 --> I[필수 입력파일 검사\n팀 7 + 은행 3]
    I -- 누락 --> J[상태 WAITING_FILES\n10분 간격 재검사]
    J -->|파일 준비됨| I
    I -- 정상 --> K[입력자료 zip 백업]

    K --> L[팀 지출계획 읽기\n표/열이름 자동 탐지]
    L --> M[요청ID 중복 정리\n변경·취소·미확정 처리]
    M --> N[카드 결제일 계산\n카드결제기준 시트]
    N --> O[은행 거래 표준화\n농협·우리·국민]
    O --> P[중복 거래 제외\n은행+거래일+금액+잔액]
    P --> Q[자동분류\n내부이체·TOP출금·온라인매출 등]
    Q --> R[거래 이력 누적\n정기지출 분석]
    R --> S[예정지출 ↔ 실제출금 대조]
    S --> T[입금 예측\n최근 12주 요일평균 × 반영률]
    T --> U[4주 일별 계획]
    U --> V[13주 주별 계획]
    V --> W[임시폴더에 결과 생성\nExcel + PDF + 확인필요]
    W --> X{재열기 검증 통과?}
    X -- 아니오 --> Y[상태 FAILED\n임시파일 정리·기존 결과 보존]
    X -- 예 --> Z[결과폴더로 이동\n덮어쓰기 금지]
    Z --> AA[상태 SUCCESS 기록\n입력 서명 저장]
    AA --> D

    D -->|입력 변경 감지| AB[트레이 알림\n'변경자료 반영' 대기]
    AB -->|사용자 승인| G
```

## 상태 전이

```mermaid
stateDiagram-v2
    [*] --> NOT_RUN
    NOT_RUN --> RUNNING: 예정시각/보완/수동 실행
    RUNNING --> SUCCESS: 모든 단계 + 재열기 검증 통과
    RUNNING --> WAITING_FILES: 필수파일 누락
    RUNNING --> FAILED: 오류 발생
    RUNNING --> PARTIAL: 누락 상태로 부분 실행(수동 허용 시)
    WAITING_FILES --> RUNNING: 10분 재검사에서 파일 확인
    FAILED --> RUNNING: 재시작/수동 실행
    PARTIAL --> RUNNING: 변경자료 반영
    SUCCESS --> RUNNING: 입력 변경 후 사용자 승인
    SUCCESS --> [*]: 다음 주로 넘어감(주차 갱신)
```

## 텍스트 요약 (10단계)

1. 시작 60초 대기 → 이번 주 완료 여부 확인 (미완료면 요일 무관 보완 실행)
2. lock으로 동시 실행 방지, 죽은 lock은 자동 복구
3. 팀 7개·은행 3개 필수파일 검사, 누락 시 WAITING_FILES + 10분 재시도
4. 입력자료 zip 백업
5. 팀 지출계획 취합 → 요청ID 기준 최신 선택, 취소·미확정 제외,
   카드 사용일 → 결제일 변환, 대외비는 분류·총액만
6. 은행 3사 거래 표준화 → 중복 제외 → 자동분류 → 이력 누적
7. 지급예정 ↔ 실제출금 대조 (불확실 건은 수동확인필요)
8. 요일별 입금 평균 × 반영률(기본 80%)로 4주 일별·13주 주별 잔액 계산
9. Excel(11개 시트)·PDF·확인필요 파일을 임시폴더에 생성 → 재열기 검증
10. 결과폴더로 이동(덮어쓰기 금지) → SUCCESS 기록 → 변경 감지 대기
