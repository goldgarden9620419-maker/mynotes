# 자금계획 자동화 — 파일 넣는 곳

이 폴더는 Obsidian(mynotes 보관함) 안에 있습니다.
**컴퓨터에서 이 폴더에 파일을 저장하면** Git 동기화를 타고 올라와,
매주 월요일 오전 9시 10분에 자동으로 취합·계산되고
결과가 `05_결과` 폴더로 다시 내려옵니다.

## 바탕화면에서 쓰기 (권장)

깊은 폴더를 찾아 들어갈 필요 없이 바탕화면에서 바로 쓸 수 있습니다.

1. `cashflow_automation\바탕화면_바로가기_만들기.bat`를 **한 번만** 더블클릭
2. 바탕화면에 생긴 **"자금계획 폴더"**를 열어 아래 표의 위치에 파일을 넣기
   (파일을 아이콘 위로 끌어다 놓아도 폴더 안으로 들어갑니다)
3. 바로 결과가 필요하면 **"자금계획 지금 실행"** 더블클릭

바탕화면의 "자금계획 폴더"는 이 보관함 폴더와 연결된 바로가기라서,
여기에 넣은 파일도 똑같이 자동 동기화·자동 계산됩니다.
(바탕화면에 별도 새 폴더를 직접 만들어 쓰면 동기화가 되지 않으니,
반드시 이 바로가기를 사용하세요.)

## 넣는 곳

| 무엇을 | 어디에 | 언제까지 |
|---|---|---|
| **전 팀 지출계획 취합 파일 (1개)** | `02_경영지원_대외비\` | 금요일 |
| 농협 최근 14일 거래내역 | `03_은행거래내역\농협\` | 월요일 09:00 전 |
| 우리은행 최근 14일 거래내역 | `03_은행거래내역\우리은행\` | 월요일 09:00 전 |
| 국민은행(2개 계좌) 최근 14일 거래내역 | `03_은행거래내역\국민은행\` | 월요일 09:00 전 |

- **지출계획은 2026-09-18부터 통일 양식 한 파일로 취합**합니다
  (`양식\지출계획_취합양식.xlsx` 참고 — 신청자 열이 있고
  확정여부·품의승인 열이 없는 형태). 파일명은 자유이고,
  같은 폴더에 여러 개가 있으면 가장 최근 파일을 사용합니다.
- 통일 취합 파일이 들어오면 `01_일반팀_지출계획\`의 팀별 개별 파일은
  **더 이상 읽지 않으므로**, 모든 팀 지출은 취합 파일에 담아 주세요.
- 승인 여부와 관계없이 전 건을 지급예정일 기준으로 반영합니다
  (진행상태가 "취소"인 행만 제외).
- 은행 파일은 내려받은 원본 그대로, 파일명 자유.
  **형식·확장자와 관계없이** 내용을 판별해 읽습니다
  (구형 XLS, XLSX, CSV/TXT, HTML 표로 저장된 엑셀 파일 모두).
  지난주 파일과 겹쳐도 자동으로 중복 제거됩니다.
- 저장 후 Obsidian이 동기화(커밋·푸시)할 때까지 잠시 열어두세요.

## 결과 받는 곳

매주 월요일 오전, 클로드가 **채팅으로 4개 파일을 보내드립니다**
(가능한 경우 `05_결과\` 폴더에도 함께 저장됩니다).
- `주간자금계획_라이브_…xlsx` — **반영률(요약!B13)을 바꾸면 즉시 재계산되는 본편**
- `주간자금계획_…xlsx` — 고정 서식 상세본 (12개 시트)
- `주간자금계획_대표보고_…pdf` — 대표 보고용
- `확인필요_…xlsx` — 그 주에 검토할 항목

## 즉시 실행이 필요할 때

두 가지 방법이 있습니다.

**방법 1 — 내 컴퓨터에서 직접 (가장 빠름, 인터넷 동기화 불필요)**

파일을 위 폴더에 넣은 뒤 `cashflow_automation\지금_실행.bat`를
더블클릭합니다. 폴더를 검색해 **수정시각 기준 최신 파일**을 자동으로
골라 계산하고, 끝나면 `05_결과` 폴더가 자동으로 열립니다.
(최초 1회만 파이썬 환경을 준비하느라 몇 분 걸립니다.
Python 3.11+ 설치 필요 — 설치 시 "Add python.exe to PATH" 체크)

터미널(PowerShell)에서 직접 실행하려면:

```
cd "내보관함경로\01-Projects\에이팜건강-주간자금계획-자동화\cashflow_automation"
.\지금_실행.bat
```

**방법 2 — 클로드에게 요청**

파일을 넣고 동기화된 뒤, 클로드 대화에서 "자금계획 실행해줘"라고
말하면 예정 시각을 기다리지 않고 바로 만들어 드립니다.

## 최초 1회 설정

1. Obsidian → 설정 → Git 플러그인에서 **자동 커밋·푸시(백업)**를 켭니다
   (예: 10분 간격). 이게 켜져 있어야 넣은 파일이 자동으로 올라갑니다.
2. 라이브 양식 파일(클로드가 채팅으로 보낸
   `주간자금계획_라이브_….xlsx`)을
   `04_기준파일\자금계획_라이브템플릿.xlsx` 이름으로 복사해 둡니다.
3. 은행 6개월 파일과 팀 파일들을 위 표의 폴더에 넣습니다.
   (지난 파일은 지우지 말고 그대로 두세요 — 중복은 자동 제거되고,
   과거 이력은 예측 정확도에 쓰입니다)
