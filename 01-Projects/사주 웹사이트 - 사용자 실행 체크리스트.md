# 사주 웹사이트 - 사용자가 직접 해야 할 일 (순서대로)

> 코드/콘텐츠 쪽은 제가 할 수 있는 만큼 다 해뒀어요. 여기서부터는 계정 생성·결제·본인 인증이 필요해서 직접 진행하셔야 하는 부분이에요. 순서대로 하나씩 하면 됩니다. 중간에 막히거나 제가 도와드릴 수 있는 부분(코드 수정, 파일 채우기 등)은 표시해뒀어요.

## 1단계 — 저장소 & 배포 (가장 먼저, 무료)
- [ ] **GitHub에 배포용 새 저장소 만들기** (예: `saju-website`) — 이 Obsidian vault(`mynotes`)와는 별개로
- [ ] `01-Projects/사주 웹사이트 - 프로토타입 코드/` 폴더 안의 파일들을 그 저장소로 복사
  - 필요한 파일: `index.html`, `celebrities.json`, `ohang_copy.json`, `privacy-policy.html`, `terms.html`, `og-image.png`, `sitemap.xml`, `celebs/` 폴더 전체
  - (`match.py`, `gen_celeb_pages.py`, `README.md`는 참고용 스크립트라 배포에는 필요 없지만, 나중에 콘텐츠 관리용으로 같이 넣어둬도 됨)
- [ ] **Vercel** 또는 **Netlify** 계정 만들고 그 저장소 연결 → 자동으로 `xxx.vercel.app` 같은 무료 주소가 생김
- [ ] 그 주소로 접속해서 실제로 잘 뜨는지 확인 (로컬에서 확인했던 것과 동일하게 동작해야 함)

## 2단계 — 도메인 연결 (선택이지만 권장)
- [ ] 가비아/후이즈/Namecheap 등에서 도메인 구매 (연 1~2만원대)
- [ ] Vercel/Netlify 설정에서 그 도메인 연결 (DNS 값 입력 — 호스팅사가 가이드 제공)
- [ ] **← 도메인이 정해지면 저한테 알려주세요.** `sitemap.xml`과 `index.html`의 OG 태그에 있는 `YOUR-DOMAIN.example`을 실제 도메인으로 바로 교체해드릴게요.

## 3단계 — 법적 문서 채우기 (제가 만든 초안에 실제 정보만 채우면 됨)
- [ ] `privacy-policy.html`의 `[YYYY-MM-DD]`(시행일), `[연락처 이메일 입력]`을 실제 값으로 교체
- [ ] `terms.html`도 동일하게 `[YYYY-MM-DD]`, `[연락처 이메일 입력]` 교체
- [ ] **← 채울 정보(이메일, 시행일)만 알려주시면 제가 대신 수정해드릴 수 있어요.**

## 4단계 — 검색엔진 등록
- [ ] Google Search Console 가입 → 사이트(도메인) 등록
- [ ] `sitemap.xml` 제출 (유명인 161명 개별 페이지가 검색에 잡히기 시작함)

## 5단계 — 애드센스 신청
- [ ] Google 애드센스(adsense.google.com) 가입 → 사이트 URL 제출
- [ ] 심사 대기 (보통 며칠~몇 주)
- [ ] 승인되면 발급받는 광고 코드를 사이트에 삽입
- [ ] **← 광고 코드 삽입은 제가 해드릴 수 있어요.** 승인 메일 받으시면 코드만 저한테 붙여넣어 주세요.

## 6단계 — (선택) Google Analytics
- [ ] Google Analytics 계정 생성, 추적 ID 발급
- [ ] **← 추적 ID 주시면 제가 사이트 코드에 연동해드릴게요.**

## 7단계 — 트래픽 만들기 (런칭 이후 계속)
- [ ] 결과 카드 공유 기능으로 SNS(인스타 스토리, 쓰레드 등)에 홍보
- [ ] 블로그/쓰레드 콘텐츠와 연계해 유입 만들기
- [ ] 반응 보면서 유명인 DB 추가 확장 검토
