# 수능잼 — 쓰레드(Threads) 글 모음

> 작성일: 2026-09-08
> 방침: 네이버 블로그·티스토리는 수익형(애드센스)으로 이미 쓰고 있어 겹치지 않도록, 수능잼 홍보는 우선 쓰레드로만 진행
> 톤: 메이커 스토리(만든 사람 1인칭) + 수험생 공감, 존댓말
> 발행 간격: 1~3일에 1편, 같은 날 여러 편 금지 · 글자 수 500자 이내 · 링크는 본문 끝에 1개만
> 자동 발행 연동 없음(수능잼은 Meta Threads API 미연동) — 복붙으로 수동 발행

## 1편 — 소개 훅 (첫 글, 프로필 고정 추천)

- [ ] 발행

```
수능 D-100 아래로 내려가면
자투리 시간까지 아까워지죠.

버스 기다리는 5분, 쉬는 시간 10분—
이럴 때 문제집 펴기는 애매하잖아요.

그래서 만들었습니다.
스마트폰으로 짧게 푸는 영어·수학 연습문제,
수능잼.

한 문제 풀고 맞으면 다음 문제,
틀리면 그 자리에서 바로 해설까지 보여줘요.

문제는 AI가 매일 새로 만듭니다.
실제 기출을 그대로 베끼는 게 아니라,
평가원 출제 패턴만 참고해서요.

suneungjam.com
```

## 2편 — '오늘의 확언' 만든 이유 (1편 발행 1~3일 뒤)

- [ ] 발행

```
수능잼 만들면서
문제만 잘 만들면 될 줄 알았는데,

베타로 써준 친구가 그러더라고요.
"문제 풀다 자신감 떨어질 때가 있어."

그래서 홈 화면 맨 아래에
'오늘의 확언' 카드를 넣었어요.
매일 바뀌는 짧은 응원 문구 하나.

문제 하나 풀 힘도
결국 마음이 버텨줘야 나오는 거니까요.

suneungjam.com
```

## 3편 — 사용법 소개 (2편 발행 1~3일 뒤)

- [ ] 발행

```
"하루에 문제집 한 장이라도"
막상 해보면 이게 제일 안 지켜지죠.

수능잼은 그래서 딱 한 문제 단위로 쪼갰어요.
어법 하나, 빈칸추론 하나,
수열 하나, 적분 하나—

이동 중에 딱 3분이면
오늘 치 하나는 채우고 갈 수 있어요.

맞히면 다음 문제로,
틀리면 그 자리에서 바로 해설 확인.
한 화면 안에서 다 끝나요.

가입 없이 바로 풀어볼 수 있습니다.
suneungjam.com
```

## 이후 소재 아이디어

- 매일 새 문제 자동 생성되는 원리(사람이 아니라 매일 아침 자동으로 채워진다는 점)
- 어법 문제 밑줄 표시처럼 실제 수능 문제 형식을 그대로 따온 디테일
- 수학 문제 손풀이 검증 과정(정확도에 신경 쓴다는 신뢰 포인트)
- 실제 사용 후기/반응 생기면 그걸 소재로

## 운영 팁

- 1편은 프로필에 고정 (쓰레드 글 ··· 메뉴 → 프로필에 고정)
- 댓글 달리면 꼭 답글 (초기엔 대화가 노출을 키움)
- 발행 여부는 이 노트의 체크박스로 기록
