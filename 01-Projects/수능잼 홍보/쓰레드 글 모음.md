# 수능잼 — 쓰레드(Threads) 글 모음

> 작성일: 2026-09-08
> 방침: 네이버 블로그·티스토리는 수익형(애드센스)으로 이미 쓰고 있어 겹치지 않도록, 수능잼 홍보는 우선 쓰레드로만 진행
> 톤: 메이커 스토리(만든 사람 1인칭) + 수험생 공감, 존댓말
> 발행 간격: 1~3일에 1편, 같은 날 여러 편 금지 · 글자 수 500자 이내 · 링크는 본문 끝에 1개만

## ✅ 자동 발행 코드 준비 완료 (9/8) — 실제 작동은 아래 설정 후

- 이 노트의 3편을 그대로 `data/threads-queue.json`(대기열)에 넣고, `app/api/cron/threads/route.ts` + `vercel.json`으로 **매일 10:10(KST) Vercel Cron이 오늘 날짜에 해당하는 항목을 자동으로 Threads에 발행**하도록 코드까지는 만들어 뒀습니다.
- ⚠️ **아직 실제로 발행되지는 않습니다.** 메타 개발자 앱 등록 + 토큰 발급은 본인 계정 인증이 필요해서 클로드가 대신할 수 없어요. 아래 "사용자가 해야 할 일" 완료 전까지는 크론이 돌아도 "환경변수 미설정" 에러만 반환합니다.
- 이후 새 쓰레드 글을 추가하고 싶으면: 이 노트에 새 편을 쓴 뒤 `data/threads-queue.json`에 `{id, status: "pending", scheduledDate: "YYYY-MM-DD", text}` 형태로 추가하고 push하면 됩니다(발행일은 KST 기준, 1~3일 간격 유지).
- 발행이 끝난 항목은 `data/threads-queue.json`에서 지우고 커밋해서 정리해 주세요(같은 날짜가 다시 오면 재발행되지 않도록 정확한 날짜 일치로만 발행하는 방식이라, 큐를 계속 깨끗하게 유지하는 게 안전합니다).

### 사용자가 해야 할 일 (메타/Vercel — 클로드가 대신 못 함)

1. **Meta 개발자 앱 만들기**: [developers.facebook.com](https://developers.facebook.com) → 새 앱 생성 → "Threads API" 제품 추가
2. **Threads 테스터로 본인 계정 연결**: 앱 설정에서 본인 Threads/Instagram 계정을 테스터로 추가하고 초대 수락
3. **권한 포함해서 access token 발급**: `threads_basic`, `threads_content_publish` 권한으로 OAuth 진행 → 단기 토큰 → **장기 토큰(60일)** 으로 교환 (하루보고 때처럼 7일마다 자동 연장되도록 구성하면 이상적)
4. **Threads 사용자 ID 확인**: 토큰 발급 후 `GET https://graph.threads.net/v1.0/me?fields=id,username&access_token=발급받은토큰` 한 번 호출해서 `id` 값 확인
5. **Vercel 프로젝트(suneungjam)에 환경변수 등록** — Project Settings → Environment Variables
   - `THREADS_ACCESS_TOKEN` = 4번에서 발급받은 장기 토큰
   - `THREADS_USER_ID` = 4번에서 확인한 Threads 사용자 ID
   - `CRON_SECRET` = 아무 임의의 랜덤 문자열(직접 생성) — Vercel Cron이 자동으로 이 값을 Authorization 헤더에 실어서 보내므로, 외부에서 이 발행 API를 함부로 호출하지 못하게 막아줌
6. 환경변수 저장하면 Vercel이 재배포되고, 그다음 날 10:10(KST)부터 정상 작동 시작

⚠️ **토큰은 반드시 Vercel 환경변수로만 등록하고, 절대 채팅이나 노트에 기록하지 마세요.** (하루보고 때와 동일한 원칙)
