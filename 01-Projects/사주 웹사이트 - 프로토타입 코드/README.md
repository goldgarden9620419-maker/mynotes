# 사주 웹사이트 프로토타입 코드

DB를 코드에서 분리해 JSON 파일로 관리하는 버전입니다.

## 파일 구성
- `celebrities.json` — 유명인 27명 데이터 (이름, 일주, 성공스토리, 습관, 모토)
- `ohang_copy.json` — 오행(木火土金水) 5개 설명 카피
- `match.py` — 매칭 로직 (일주 정확 일치 → 없으면 오행 기준 폴백, 생년월일 해시 기반 고정 시드 적용)

## 실행 방법
```bash
pip install lunar_python
python3 match.py
```

## 왜 JSON으로 분리했나
- 유명인 DB가 늘어날수록(60갑자 커버리지 확장 등) 코드 수정 없이 데이터만 추가/수정 가능
- 콘텐츠 담당자가 코드를 몰라도 `celebrities.json`만 편집하면 되도록
- 추후 웹 프레임워크로 이식할 때 API가 이 JSON을 그대로 응답으로 내려줄 수도 있음

## 검증 결과
- `celebrities.json` 로드 시 27명 정상 로드 확인
- 스티브 잡스 생일(1955-02-24) 입력 시 정확 매칭으로 본인이 나옴
- 같은 날짜(1990-03-15) 반복 조회 시 항상 동일한 3명 반환 (시드 고정 재확인)
