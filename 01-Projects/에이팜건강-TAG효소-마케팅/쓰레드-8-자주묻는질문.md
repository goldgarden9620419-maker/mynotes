# 쓰레드 초안 8 — 자주 묻는 질문(Q&A)

금요일 루프(2026-10-23) 실행분. 원료 소개 시리즈(T·A·G)가 끝나서, 지금까지 소개한 사실들을 "자주 묻는 질문 4개"로 묶는 형식으로 바꿨다. 새로운 사실이나 효능은 추가하지 않고, 공식 페이지에 있는 원료·사과맛·섭취 연령·공법만 썼다.

## 게시 전 확인사항
- [x] 재직 고지 문구 포함 (사용자가 10/2에 고른 "애용자로서 공유" 톤)
- [x] 신규 효능 주장 없음 — 원료 이름, 사과맛, 3세 이상~중장년층 섭취 가능, 특허받은 저분자 발효 공법만 사용 (모두 공식 페이지 기재 사항). "흡수율"·"소화" 같은 기능 표현은 넣지 않음
- [x] "신제품" 표현 없음, 포 수(30포/60포 미확인)도 넣지 않음
- [x] "질문을 받았다" 같은 지어낸 경험은 넣지 않음 — "자주 나오는 질문들을 모아봤다"로 표현
- [x] 댓글 질문 유도 문장 제거 (2026-10-23 사용자 요청: 답글 부담) — "효소 고르실 때 참고가 됐으면 좋겠어요."로 교체
- [ ] **아이 섭취 문구** — "3세 이상"은 공식 페이지 기재 사항이지만, 아이 대상 표현이라 회사에서 문제없는지 한 번 확인 권장

## 본문 (387자)

```
효소 얘기를 하면 자주 나오는 질문들이 있어서, 국민 T.A.G 효소 기준으로 한 번에 모아봤어요.

Q. T.A.G가 무슨 뜻이에요?
테프(T), 애사비(A), 글루텐 분해 유산균(G), 세 원료의 앞글자예요.

Q. 효소 특유의 맛 때문에 못 먹겠던데요?
그래서 사과맛으로 나왔어요. 맛 때문에 효소를 포기했던 분들께 제일 먼저 말씀드리고 싶은 부분이에요.

Q. 아이도 먹을 수 있어요?
제품 페이지 기준으로 3세 이상부터 중장년층까지 먹을 수 있다고 나와 있어요.

Q. 어떻게 만든 거예요?
특허받은 저분자 발효 공법으로 만들었어요.

효소 고르실 때 참고가 됐으면 좋겠어요.

제가 다니는 회사 제품이기도 하지만, 직접 먹어보면서 좋아하게 돼서 애용자로서 공유하고 싶어 올려봐요 🙂
```
