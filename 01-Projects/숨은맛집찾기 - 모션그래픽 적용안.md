## 1. 목표
- 모션은 **장식이 아니라 안내**: "지금 무슨 일이 일어나는지"(검색 중·결과 도착·찜 완료)를 보여 줄 때만 쓴다.
- 속도·광고·접근성을 해치지 않는다: CLS 0 유지, LCP 늦추지 않기, "동작 줄이기" 설정 존중.

## 3. 원칙 (가드레일)
1. **transform·opacity만** 움직인다. 높이·위치를 바꿔 내용을 밀어내는 애니메이션 금지 → CLS 0.
2. **LCP 요소(히어로 이미지·h1)는 처음부터 보이게** 둔다. 등장 효과는 그 외 요소만.
3. **동작 줄이기 설정 존중**: 루트에 `MotionConfig reducedMotion="user"` + CSS `prefers-reduced-motion`에서 배경 블롭 정지.
4. **SSR에서 숨겨진 상태로 시작하지 않는다**(글 본문). JS가 늦거나 막혀도 내용이 보여야 함(애드센스·검색 로봇).
5. **광고 주변 금지**: 자동광고가 들어갈 본문 흐름에서 클릭 유도·주의 끌기 모션 금지, 레이아웃 이동 금지(오클릭 방지).
6. 길이 150–400ms. **무한 반복은 로딩 상태에만**.

| # | 내용 | 효과 |
|---|---|---|
| 1-1 | 전역 `MotionConfig reducedMotion="user"`, 배경 블롭 CSS `prefers-reduced-motion` 정지 | 접근성 |

| 1-4 | 찜 하트 "톡" 튀는 효과(scale), 주소 복사·공유 완료 체크 표시 전환 | 동작 확인 피드백 |

### 하지 않을 것
- 히어로 배경 영상·Lottie 같은 무거운 애니메이션(용량·LCP).
- 글 본문 스크롤 등장(fade-in) — 4번 원칙 위반, 애드센스 "얇은 콘텐츠" 오판 위험.
- 숫자 카운트업 등 광고처럼 보이는 주의 끌기.

## 5. 자체 검증 (Claude)
| 위험 | 판단 | 대응 |
|---|---|---|
| 히어로 등장 효과가 LCP를 늦춤 | 실제 위험 (투명 요소는 LCP로 안 잡힘) | 이미지·h1 제외 (1-5) |
| 글 스크롤 등장이 SEO·애드센스에 불리 | 실제 위험 (SSR HTML이 opacity:0) | 글 본문은 모션 제외 |
| 자동 스크롤이 사용자를 놀라게 함 | 중간 | 모바일·결과 제목이 화면 밖일 때만, 동작 줄이기면 즉시 이동 |
| 배경 블롭 축소로 분위기 약해짐 | 낮음 | PC는 유지, 모바일만 축소 |
| 라이브러리 통일로 깨짐 | 낮음 | API 동일(motion은 framer-motion 재수출). 빌드·화면 테스트로 확인 |
