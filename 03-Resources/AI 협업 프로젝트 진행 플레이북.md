## 공통 원칙 4가지
1. **역할 분담:** ChatGPT가 넓게 설계·진단하고, Claude가 검증해서 구현한다. (자금계획 사례: Claude가 ChatGPT가 놓친 "지난자료 즉시 삭제" 버그를 재현해 잡고, 과장된 지적은 실제 영향을 따져 낮춤)
2. **작게 나눠서:** 기능 하나씩 → 테스트 → 커밋 → 다음 기능. 한 번에 다 만들지 않는다.
3. **안전장치 먼저:** 운영 중인 것은 복사본에서 작업, 민감정보는 가리고, 백업 후 반영.
4. **기록:** 결정과 진행 상황은 vault 노트에 남긴다.

| 단계 | 🆕 새 자동화 | 🌐 새 웹사이트 | 🔧 기존 프로그램 개선 |
|---|---|---|---|
| 0. 정리 | claude.ai 대화창에서 목표·입력·출력 정하기 | 목표·대상·페이지 구성·수익 모델 정하기 | 불편한 점과 목표 정하기 |

| 2. 설계 | ChatGPT 설계 → Claude 검증 | 같음 (페이지 구조·기술 선택 포함) | ChatGPT 진단 → Claude 검증 → 개선 후보 표 |
| 3. 구현 | 기능 단위로 테스트·커밋 | 화면 단위로 만들고 브라우저로 확인 | 묶음 단위로 재현 테스트 → 수정 |

| 5. 마무리 | 실제 데이터로 실행 확인 | **배포**(GitHub → Vercel 등) + 도메인·애드센스 | 백업 → 변경분만 패치 반영 → 원본에서 테스트 |
| 6. 기록 | vault 노트 | vault 노트 | vault 노트 |

## 웹사이트에 추가로 챙길 것
- **GitHub 연결:** 배포하려면 코드를 GitHub에 올려야 함. PC에서 GitHub 로그인 설정은 처음 한 번만 (첫 웹사이트 때 같이 진행)
- **배포 서비스:** 정적 사이트는 Vercel이나 GitHub Pages로 무료 시작 가능
- **비밀 키 관리:** API 키 등은 코드에 넣지 말고 `.env` 파일에 두고 `.gitignore`로 제외
- 적용 후보: 사주 웹사이트, 숨은맛집찾기, 수능잼

## 기존 프로그램 개선 시 안전장치 (자금계획 사례에서 정리)
- 작업은 `ai-work\○○-dev` 복사본에서만 (`.venv`·`__pycache__`·`build`·`dist` 제외), 원본은 절대 직접 수정하지 않음
- 복사본 `git init` 후 "원본 기준" 커밋 → 민감정보(계좌번호·이름·금액)를 복사본에서만 가짜 값으로 교체 → 별도 커밋
- Codex 실행 규칙: `-s read-only` + `-C 복사본폴더` + "`.git` 이력과 `.venv`는 보지 마"
- 실제 업무 데이터 확인은 Claude가 로컬에서 "읽기만" (Codex에 보내지 않음)
- 원본 반영: 백업 → "가리기 커밋 이후 변경분"만 패치 → 패치에 설정 파일·가짜 값이 있으면 멈춤 → 원본에서 테스트 → 보고 후 마무리
- 원본이 Obsidian 저장소 안에 있으면 git 브랜치 변경·커밋 금지 (Obsidian이 관리)

## 시작할 때 쓰는 문장 (PC Claude에 붙여 넣기)

**새 프로젝트**
```
CLAUDE.md의 협업 규칙대로 ○○을 만들어줘.
- 프로젝트 폴더: ○○ (만든 뒤 그 안에서 git init)
- 목표: ○○
- 입력/출력: ○○ → ○○
- 요구사항: ○○, ○○
- 단계마다 짧게 보고하고, 설계가 끝나면 구현 전에 멈춰서 나한테 확인받아줘
```

**기존 프로그램 진단**
```
아래 순서로 "진단만" 해줘. 원본 폴더의 파일은 절대 수정하지 마.
1. 원본(경로)을 .venv 등 제외하고 ai-work\○○-dev 로 복사 → git init → "원본 기준" 커밋 → 테스트 실행 결과 보고
2. 민감정보가 있으면 복사본에서만 가짜 값으로 바꾸고 목록 보고 → 테스트 재실행
3. codex exec --skip-git-repo-check -s read-only -C ○○-dev "코드를 점검해서 개선점을 우선순위별로 정리해줘. .git 이력과 .venv는 보지 마" → docs/diagnosis-gpt.md
4. 네가 검증해서 최종 개선 후보 표(번호/항목/이유/난이도/예상 효과) → docs/diagnosis-final.md. 코드는 아직 고치지 마
```

## 제일 중요한 습관
- **PC Claude로 바로 가지 말고, 먼저 claude.ai 대화창에서 "뭘 만들지" 10분 정리하기.** 목표와 입력/출력이 분명할수록 PC Claude와 ChatGPT가 정확하게 일한다.
- 설계가 끝나면 **구현 전에 한 번 멈춰서 확인**하기.
- 큰 변경은 **묶음(1차·2차…)으로 나누고**, 묶음마다 반영·확인 후 다음으로.
