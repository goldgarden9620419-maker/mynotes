# AI 협업 사용 가이드 (ChatGPT+Claude)

- 메모장용 원본: 같은 폴더의 `.txt` 파일 (Windows 메모장으로 열기)
- 관련 노트: [[ChatGPT + Claude 협업 워크플로우 설정 (Codex CLI 연동)]] · [[AI 협업 프로젝트 진행 플레이북]]

```text
==================================================
 AI 협업 사용 가이드 (ChatGPT 설계 + Claude 검증·구현)
 작성일: 2026-10-05
==================================================

[ 한 줄 요약 ]
PowerShell에서 ai-work 폴더로 이동 → claude 실행 → "협업 규칙대로 ○○ 만들어줘"


--------------------------------------------------
 1. 시작하기 (매번 이 순서)
--------------------------------------------------
1) 시작 버튼 → "PowerShell" 검색 → 실행

2) 작업 폴더로 이동
   cd ~\ai-work

3) Claude 실행
   claude

4) 처음 보는 폴더면 "신뢰하겠냐"는 질문이 나옴
   → 방향키 ↓ 로 "Yes, I trust this folder" 선택 → Enter

※ C:\WINDOWS\system32 에서 바로 claude 실행하지 말 것 (시스템 폴더)
※ C:\Users\AP (홈 폴더 전체)도 신뢰하지 말 것 → 항상 ai-work 안에서


--------------------------------------------------
 2. 작업 시키기 (복사해서 ○○만 바꿔 쓰기)
--------------------------------------------------
[새 프로젝트]
CLAUDE.md의 협업 규칙대로 ○○을 만들어줘.
- 프로젝트 폴더: ○○ (만든 뒤 그 안에서 git init)
- 요구사항: ○○, ○○, ○○
- 각 단계(설계 → 검증 → 구현 → 교차 리뷰)가 끝날 때마다 무엇을 했는지 짧게 알려줘

[기존 프로젝트 고치기]
○○ 폴더의 프로젝트에서 ○○ 기능을 추가(수정)하고 싶어.
CLAUDE.md의 협업 규칙대로 ChatGPT에게 개선 설계를 받고, 네가 검증한 다음 고쳐줘.

[ChatGPT 의견만 물어보기]
터미널에서 codex exec --skip-git-repo-check "○○ 질문" 를 실행해서 ChatGPT의 답을 받고,
네가 검토해서 장단점을 알려줘

[오류 고치기]
방금 이런 오류가 났어: (오류 메시지 붙여넣기)
원인을 찾아서 고쳐줘.


--------------------------------------------------
 3. 진행 흐름 (자동으로 이렇게 돌아감)
--------------------------------------------------
① 설계   : ChatGPT(codex exec)가 구조·계획 작성 → docs/design-gpt.md
② 검증   : Claude가 허점·보안·엣지케이스 점검 → docs/design-final.md
③ 구현   : Claude가 코드 작성 + 테스트 실행
④ 교차리뷰: ChatGPT가 코드 리뷰 → Claude가 타당한 것만 반영

- 3~6분 정도 걸림
- 실행 허락을 물으면 Yes
- 끝나면 사용법(실행 명령)을 알려줌


--------------------------------------------------
 4. 끝난 뒤 할 일
--------------------------------------------------
1) 직접 실행해서 확인 (Claude가 알려준 사용법대로)
   예) cd C:\Users\AP\ai-work\todo-app
       python todo.py list

2) 저장(커밋): Claude 입력창에
   커밋해줘

3) Claude 종료
   /exit


--------------------------------------------------
 5. 자주 쓰는 명령어
--------------------------------------------------
[PowerShell]
cd ~\ai-work                  작업 폴더로 이동
cd ○○                        하위 폴더로 이동
cd ..                         상위 폴더로
dir                           현재 폴더의 파일 목록
claude                        Claude 실행
codex exec --skip-git-repo-check "질문"   ChatGPT에게 바로 질문
codex login status            ChatGPT 로그인 상태 확인
claude --version              Claude 버전 확인
codex --version               Codex 버전 확인

[Claude 입력창 안에서]
/exit                         Claude 종료
/clear                        대화 내용 비우고 새로 시작 (다른 작업 시작할 때)
Esc                           진행 중인 작업 멈추기
Shift + Tab                   모드 전환 (auto mode on/off 등)
↑                             이전에 입력한 문장 다시 불러오기


--------------------------------------------------
 6. 어디에 명령하나?
--------------------------------------------------
[PC의 Claude 창 (PowerShell)]
- 코드 짜기, 자동화 도구 만들기, 프로그램 실행
- ChatGPT(Codex) 호출은 여기서만 가능

[claude.ai 대화창 (클라우드)]
- 아이디어 정리, 계획 세우기
- 오류 화면 캡처해서 상담
- Obsidian 노트(mynotes)에 기록 저장
- PC 파일에는 접근 불가


--------------------------------------------------
 7. 문제가 생겼을 때
--------------------------------------------------
[codex 명령이 안 됨 / 로그인 풀림]
   codex login
   → 브라우저에서 ChatGPT 계정으로 로그인

[claude 로그인 방법을 물어봄]
   "Claude account with subscription" 선택
   ("Anthropic Console"은 API 과금이라 선택 X)

[codex 로그인 방법을 물어봄]
   "Sign in with ChatGPT" 선택 ("API key"는 과금이라 선택 X)

["Git 저장소가 아니다" 경고]
   codex exec 뒤에 --skip-git-repo-check 붙이기

[스크립트를 실행할 수 없습니다 (실행 정책 오류)]
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

[npm warn allow-scripts 경고]
   claude --version 이 정상으로 나오면 무시해도 됨

[업데이트]
   npm install -g @openai/codex
   npm install -g @anthropic-ai/claude-code

[그래도 안 되면]
   화면 캡처 → claude.ai 대화창에 보내기


--------------------------------------------------
 8. 팁
--------------------------------------------------
1) 입력창에 흐리게 보이는 문장은 "추천 문장"일 뿐.
   Enter를 바로 누르면 그 작업이 실행되니 주의.

2) 프로젝트마다 하위 폴더를 따로 만들기.
   (ai-work\todo-app, ai-work\blog-tool ...)

3) 요구사항은 구체적으로.
   "편하게 만들어줘" (X)
   "엑셀 파일을 읽어서 월별 합계를 새 시트에 만들어줘" (O)

4) 큰 작업은 쪼개서.
   한 번에 다 시키지 말고 기능 하나씩 → 확인 → 커밋 → 다음 기능

5) 다른 작업을 시작할 땐 /clear 로 대화를 비우기.
   (이전 작업 내용이 섞이지 않음)

6) 회사 자료·개인정보 파일은 ai-work 밖에 두고,
   필요한 파일만 복사해서 쓰기.

7) 비용: ChatGPT·Claude 구독 안에서 사용 (API 키를 쓰지 않는 한 추가 요금 없음).
   단, 구독별 사용량 한도는 있으니 너무 많이 쓰면 잠시 제한될 수 있음.

8) MCP 방식(claude mcp add codex ...)은 쓰지 않음.
   2026-08 OpenAI가 codex mcp-server 지원 종료 → codex exec 방식 사용.

9) 협업 규칙 파일 위치: C:\Users\AP\ai-work\CLAUDE.md
   규칙을 바꾸고 싶으면 Claude에게 "CLAUDE.md에 ○○ 규칙 추가해줘"
   (바꾼 규칙은 claude를 껐다 켜야 적용)

--------------------------------------------------
 9. 프로젝트 진행 플레이북 (새로 만들 때 / 고칠 때)
--------------------------------------------------
[공통 원칙]
1) 역할 분담: ChatGPT가 넓게 설계·진단 → Claude가 검증·구현
2) 작게 나눠서: 기능 하나씩 → 테스트 → 커밋 → 다음
3) 안전장치 먼저: 운영 중인 건 복사본에서, 민감정보는 가리고, 백업 후 반영
4) 기록: 결정과 진행 상황은 vault 노트에

[진행 순서]
0. 정리   : claude.ai 대화창에서 목표·입력·출력 먼저 정하기 (10분)
1. 준비   : 새 것 → ai-work\프로젝트명 + git init
            고칠 것 → ai-work\○○-dev 복사본 + 민감정보 가리기
2. 설계   : ChatGPT 설계(또는 진단) → Claude 검증
            ※ 설계 끝나면 구현 전에 멈춰서 내가 확인
3. 구현   : 기능(또는 묶음) 단위로 테스트 → 커밋
4. 리뷰   : ChatGPT 교차 리뷰 → 타당한 것만 반영
5. 마무리 : 자동화 → 실제 데이터로 실행 확인
            웹사이트 → GitHub 올리기 → Vercel 등으로 배포 → 도메인·애드센스
            기존 개선 → 백업 → 변경분만 패치 반영 → 원본에서 테스트
6. 기록   : vault 노트

[웹사이트 추가 체크]
- GitHub 로그인 설정은 처음 한 번만 (첫 웹사이트 때)
- API 키 등 비밀 값은 .env 파일에 두고 .gitignore로 제외
- 모바일 화면·속도 점검

[새 프로젝트 시작 문장 - PC Claude에 붙여넣기]
CLAUDE.md의 협업 규칙대로 ○○을 만들어줘.
- 프로젝트 폴더: ○○ (만든 뒤 그 안에서 git init)
- 목표: ○○
- 입력/출력: ○○ → ○○
- 요구사항: ○○, ○○
- 단계마다 짧게 보고하고, 설계가 끝나면 구현 전에 멈춰서 나한테 확인받아줘

[기존 프로그램 고칠 때 꼭 지킬 것]
- 원본은 직접 수정 금지, 복사본(○○-dev)에서만 작업
- Codex 실행: codex exec --skip-git-repo-check -s read-only -C ○○-dev "..."
  + 프롬프트 끝에 ".git 이력과 .venv는 보지 마"
- 실제 업무 데이터 확인은 Claude가 "읽기만", Codex에는 보내지 않기
- 원본 반영 순서: 백업 → 변경분만 패치 → 가짜값 섞였는지 검사 → 원본에서 테스트

(자세한 내용: vault 03-Resources\AI 협업 프로젝트 진행 플레이북.md)
```
