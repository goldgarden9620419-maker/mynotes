## 1. 클로드 힉스필드 MCP 설치 가이드 (복습)

[Higgsfield MCP 전용 링크](https://higgsfield.ai/s/higgsfield-mcp-v-2-ig-yeonsidesign-koieUM)

### 준비물
- Claude 계정
- Higgsfield 계정
- Higgsfield MCP 연결 주소 (아래)

```
https://mcp.higgsfield.ai/mcp
```

### 설치 순서
1. Claude 사이드바에서 **[사용자 지정]** 클릭 ([claude.ai/new](https://claude.ai/new))
2. **[커넥터]** 클릭 → **[+ 버튼]** 클릭
3. 커스텀 커넥터에 이름(`higgsfield`)과 위 MCP 링크 입력
4. `higgsfield` 커넥터에서 **연결** 버튼 클릭
5. Higgsfield 접근 권한 **허용(Allow)**
6. 마지막으로 세 개 탭 모두 **항상 허용** 체크

## 2. 클로드 스킬 적용하는 방법

- 아래 세 개 파일 첨부하면 끝

  - `asmr-mukbang-SKILL.md`
  - `SKILL(1).md`
- [드라이브 링크](https://naver.me/xG0Rat3r) (파일 다운로드가 어려울 경우)

## 3. 힉스필드 MCP 스킬 3종 세트

### ① ASMR mukbang (ASMR 먹방 스킬)
- 이미지 모델: GPT Image 2
- 영상 모델: Seedance 2.0

사용 예시:
```
모델 이미지 (없다면 ② AI influencer 스킬 참고)
음식 이미지 삽입

명랑핫도그 먹방 만들어줘 /asmr-mukbang
```

- 영상을 바로 뽑으면 135 크레딧이 소모되므로, 이미지를 먼저 생성해서 이상한 부분이 있는지 체크
- 프롬프트 수정도 복붙 없이 자연어로 요청하면 새로 생성됨
- 마음에 드는 이미지가 나오면 그때 영상 생성 요청
- 몇 크레딧이 드는지도 함께 안내하도록 세팅됨

> 가상의 한국인 여성 뷰티 모델 생성. 전체 무드는 맑고 깨끗하면서도 영한 분위기의 트렌디한 K-뷰티 화보. 너무 성숙하거나 강한 느낌보다는 청초하고 세련된 20대 초반~중반 무드가 느껴지는 얼굴. 얼굴형은 매끄럽고 자연스러운 타원형, 이목구비는 또렷하지만 과하지 않고 부드럽고 정돈된 인상. 눈은 크고 맑은 편이며 부드럽게 트인 눈매, 자연스러운 애교살, 깨끗한 눈동자, 섬세하고 길게 올라간 속눈썹. 메이크업은 투명하고 깨끗한 피부 표현 중심의 내추럴 K-뷰티 메이크업, 은은한 핑크빛 아이메이크업, 생기 있는 연핑크 블러셔, 촉촉한 누드핑크 립. 피부는 깨끗하고 투명한 윤광 피부, 과한 보정 없이 매끈하고 부드러운 피부결과 은은한 광채 표현.
>
> 표정은 무표정에 가깝지만 분위기 있고 청량한 느낌, 차분하면서도 자연스럽게 카메라를 응시하는 시선. 헤어는 다크브라운~블랙 계열의 자연스러운 긴 생머리 또는 아주 부드러운 웨이브, 잔머리가 살짝 내려와 얼굴선을 자연스럽게 감싸는 느낌.
