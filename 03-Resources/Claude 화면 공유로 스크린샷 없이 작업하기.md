# Claude 화면 공유로 스크린샷 없이 작업하기

## 결론 (최종 채택 방법)
Claude 데스크톱 앱에는 실시간 화면 공유 기능이 없음을 확인함 (2026-08-07 테스트).
대신 **캡처 도구 + 클립보드 붙여넣기** 방식이 사실상 실시간에 가깝게 작동하며, 이걸로 충분하다고 판단해 최종 채택함.
완전한 실시간 영상 스트리밍은 Claude가 영상 스트림을 받는 구조가 아니라서 코딩으로도 구현 불가.

## 최종 워크플로우 (테스트 완료, 사용 중)
1. `Win + Shift + S` (또는 PC에 설치된 캡처 도구, 예: 에스캡처) 실행
2. 원하는 영역 캡처 → 클립보드 복사 옵션으로 저장
3. Claude 대화창 클릭 → `Ctrl + V` 로 바로 붙여넣기
4. 필요한 설명 텍스트와 함께 전송

기존의 "스크린샷 저장 → 파일 찾기 → 업로드" 과정 없이 캡처 즉시 전송 가능해서 번거로움이 크게 줄어듦.

## 확인된 사실 (2026-08-07 테스트 기록)
- 환경: Windows, Claude 데스크톱 앱(채팅/Cowork/Code 통합 앱) 설치·로그인 완료
- `+` 메뉴(파일 또는 사진 추가, 스킬, 커넥터, 플러그인) 확인 결과 실시간 화면 공유 옵션 없음
- 캡처 → 클립보드 → Ctrl+V 붙여넣기 방식은 정상 작동 확인함

## 검토했지만 채택하지 않은 대안
- **로컬 Claude Code CLI + 자동 스크린샷 폴더 감시**: 몇 초마다 자동 캡처해서 폴더에 저장하고 Claude Code가 최신 파일을 읽는 "준실시간" 방식. 구현 가능하지만 로컬 CLI 설치가 필요하고 캡처+붙여넣기 방식으로 충분하다고 판단해 보류.
