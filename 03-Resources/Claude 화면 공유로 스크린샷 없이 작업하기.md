# Claude 화면 공유로 스크린샷 없이 작업하기

## 목표
매번 화면을 캡처해서 붙여넣는 번거로움을 없애고, Claude가 실시간으로(또는 훨씬 빠르게) 화면을 보면서 같이 작업하도록 환경을 만든다.

## 환경
- OS: Windows
- 현재 사용 중: claude.ai/code (브라우저, Claude Code 세션) — 이 화면 자체는 실시간 화면 보기 기능이 없음

## 단계별 작업 스케줄

### 1단계 — Claude 데스크톱 앱 설치 (Windows)
- https://claude.ai/download 에서 Windows용 Claude 데스크톱 앱 다운로드 및 설치
- 기존 계정으로 로그인

### 2단계 — 화면 공유 기능 확인
- 데스크톱 앱에서 새 대화 시작 → 화면 공유(Screen Sharing) 옵션이 보이는지 확인
- 계정 플랜/버전에 따라 지원 여부가 다를 수 있음. 안 보이면 앱 최신 버전인지 확인 후 재확인
- 지원되면: 화면 공유를 켜고 실시간으로 작업 화면을 보여주면서 대화 진행 (스크린샷 붙여넣기 불필요)

### 3단계 — (화면 공유 미지원 시 대안) 빠른 캡처 루틴
화면 공유가 없거나, 지금처럼 claude.ai/code 브라우저 세션을 계속 쓰고 싶을 때:
- `Win + Shift + S` → 원하는 영역 캡처 (클립보드에 자동 저장됨)
- 대화창에 바로 `Ctrl + V` 로 붙여넣기
- 스크린샷 저장 → 파일 찾기 → 업로드하는 기존 방식보다 훨씬 빠름

### 4단계 — (선택) 로컬 Claude Code CLI + 자동 저장 폴더 연동
터미널에서 로컬 Claude Code CLI를 설치해서 쓰는 경우:
- 스크린샷 저장 폴더를 하나 지정 (예: `C:\Users\<사용자명>\Screenshots`)
- Windows 캡처 도구 설정에서 "자동 저장 위치"를 이 폴더로 지정
- Claude Code에게 "방금 저장된 스크린샷 확인해줘"라고 요청하면 해당 폴더에서 최신 파일을 읽어서 확인 가능

### 5단계 — 실제 작업 시작
1~4단계 중 본인 환경에 맞는 방법을 확정한 뒤, 그 방법으로 실제 작업(예: 티스토리 승인 작업, 웹사이트 작업 등)을 이어서 진행
