## 📐 1편 CHAPTER 3 | AI가 알아듣는 설계도 만들기 (PRD)

### STEP 1. PRD 개념 이해
- [ ] PRD 없이 개발하면 어떻게 되는지 이해했다 — 💡 A친구: 70시간·50만 원·완성도 60% / B친구: 25시간·5천 원·완성도 95%
- [ ] PRD 핵심 3가지를 말할 수 있다 — 💡 뭘 만드나 / 누구를 위한가 / 어떻게 작동하나
- [ ] ERD(데이터 설계도)가 뭔지 대략 안다 — 💡 서랍장 구조 — users/records/settings 등 어디에 뭘 저장할지
- [ ] TRD(기술 설계서)가 뭔지 대략 안다 — 💡 건축 재료 목록 — 프론트/백엔드 기술 스택

### STEP 2. BON.AI PRD 버튼으로 설계도 자동 생성
- [ ] BON.AI에서 'PRD' 버튼을 클릭했다 — 💡 Business 버튼과 다른 별도 버튼
- [ ] BM 설계서 내용을 PRD 버튼에 붙여넣었다
- [ ] PRD가 자동 생성됐다 (ERD·TRD·화면구성도·개발순서까지 포함)
- [ ] 결과물을 전체 복사했다

### STEP 3. Cursor에서 PRD 파일 생성
- [ ] Cursor 채팅창에 복사한 PRD 내용을 붙여넣었다
- [ ] Cursor 화면 내 'PRD' 버튼을 클릭했다
- [ ] 왼쪽 폴더에 'PRD.MD' 파일이 NEW로 생성된 걸 확인했다
- [ ] PRD 내용을 읽고 내 아이디어와 맞는지 검토했다
- [ ] 틀린 부분은 '000 부분을 이렇게 변경해줘'로 수정했다
- [ ] MVP 핵심 기능을 딱 3가지로 압축했다 — 💡 나머지는 전부 '나중에'로 처리

> 📌 PRD 완성 기준: AI가 읽고 어떤 서비스인지 100% 이해할 수 있어야 한다. 모호한 표현 없이 구체적으로.

## 🏗️ 2편 | 건물 구조 이해하기 (프론트 / 백엔드 / 유지보수)

### Chapter 1 — 프론트엔드 (건물 외관)

- [ ] 코드에 API 키를 직접 쓰면 안 된다는 걸 안다 — 💡 GitHub 공개 저장소에 올라가면 해킹 위험
- [ ] 보안(로그인 안 한 사람 차단)을 AI에게 맡길 수 있다는 걸 안다
- [ ] 오류 발생 시 에러 메시지를 Cursor에 그대로 붙여넣으면 됨을 안다
- [ ] GitHub으로 코드를 저장하면 언제든 되돌릴 수 있음을 안다

- [ ] 요금제 페이지(무료/유료 플랜)가 정상 생성됐는지 확인했다
- [ ] AI가 일회성 결제로 만들었을 때 '정기결제 구독형으로 바꿔줘'라고 다시 지시했다 — 💡 AI가 처음엔 일회성 결제로 만드는 경우가 많음
- [ ] 테스트 결제창이 정상적으로 뜨는지 확인했다
- [ ] 카드 등록 후 정기구독 시작 버튼이 작동하는지 확인했다

### STEP 5. 배포 직전 사전 체크 (필수!)
- [ ] Cursor에서 내 작업 폴더가 올바르게 열려 있는지 확인했다 — 💡 틀린 폴더면 File → Open Folder로 다시 지정
- [ ] Cursor에서 Supabase MCP 초록 버튼 + '20 tools enabled' 상태인지 확인했다
- [ ] Vercel 대시보드에서 내 프로젝트 이름과 GitHub 저장소 주소가 맞는지 확인했다

### STEP 6. Vercel에 1차 배포
- [ ] '프로덕션으로 지금 프로젝트 배포해줘'라고 Cursor에게 지시했다
- [ ] Vercel 대시보드에서 'Deployments' 탭을 눌러 배포 상태를 확인했다
- [ ] Vercel이 자동 생성한 임시 URL(xxx.vercel.app)을 받았다
- [ ] 임시 URL로 접속해서 웹사이트가 온라인에서 열리는 걸 확인했다

> ⚠️ 배포 후 서비스가 안 되면? → env.local의 키들을 Vercel에 별도 등록해야 한다. 아래 STEP 7 필수!

### STEP 7. Vercel 환경변수 등록 (필수!)
- [ ] Vercel 대시보드에서 내 프로젝트로 들어갔다
- [ ] 'Settings' → 'Environment Variables' 메뉴를 찾았다
- [ ] 'Add Environment Variable' 또는 'Import .env' 버튼을 눌렀다
- [ ] NEXT_PUBLIC_SUPABASE_URL 키와 값을 등록했다
- [ ] NEXT_PUBLIC_SUPABASE_ANON_KEY 키와 값을 등록했다
- [ ] NEXT_PUBLIC_TOSS_CLIENT_KEY 키와 값을 등록했다
- [ ] TOSS_SECRET_KEY 키와 값을 등록했다
- [ ] TOSS_WEBHOOK_SECRET 키와 값을 등록했다
- [ ] 'Save' 버튼을 눌러 저장했다
- [ ] 환경변수 저장 후 Vercel에서 Redeploy(재배포)를 실행했다 — 💡 저장만 하면 안 됨, 반드시 재배포 해야 적용됨
- [ ] 재배포 완료 후 임시 URL에서 서비스가 정상 작동하는지 재확인했다

> 📌 env.local을 직접 업로드하려면 'Import .env' 버튼을 클릭해 파일을 선택하면 한 번에 등록 가능하다.

### STEP 8. 커스텀 도메인 구매 및 연결
- [ ] Vercel 대시보드 → 내 프로젝트 → 'Domains' → 'BUY' 버튼을 눌렀다 — 💡 Vercel 안에서 바로 구매 가능. 외부 사이트도 OK
- [ ] 원하는 도메인 이름을 검색하고 가격을 확인했다 — 💡 매년 갱신 필요 (1년 단위 결제)
- [ ] 도메인 구매를 완료했다
- [ ] Vercel 대시보드에서 'Assign Custom Domain'을 눌렀다
- [ ] 구매한 도메인을 Vercel에 연결했다
- [ ] 커스텀 도메인으로 접속이 되는지 최종 확인했다
