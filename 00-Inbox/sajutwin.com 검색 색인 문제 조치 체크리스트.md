- 작성일: 2026-08-08
- 출처: Google Search Console > 색인 생성 > 페이지 (sajutwin.com)

## 현재 상태
- 색인 생성됨: 0개
- 색인이 생성되지 않음: 3개 (이유 2가지)

## 이유별 조치

### 1. 리디렉션이 포함된 페이지 (1개)
- [ ] 서치 콘솔 표에서 해당 URL 확인
- [ ] 의도한 리디렉션(http→https, www 통일 등)인지 확인 → 의도한 것이면 정상, 최종 도착 URL이 색인되고 있는지만 체크
- [ ] 의도치 않은 리디렉션이면 원인(워드프레스 설정 / .htaccess / 플러그인 등) 확인 후 수정

### 2. 크롤링됨 - 현재 색인이 생성되지 않음 (2개)
- [ ] 서치 콘솔 상단 검색창에 URL 입력 → "URL 검사" 실행
- [ ] "색인 생성 요청" 버튼 클릭
- [ ] 페이지 콘텐츠 보강 (너무 얇거나 다른 페이지와 유사하면 안 됨)
- [ ] 다른 페이지에서 해당 URL로 내부 링크 추가
- [ ] Sitemaps 메뉴에서 사이트맵 정상 제출 여부 확인

### 3. 공통
- [ ] 사이트가 최근 생성된 경우, 구글 판단까지 며칠~몇 주 소요될 수 있음 → 위 조치 후 대기
- [ ] 1~2주 뒤 서치 콘솔 재확인
