# 유튜브 기획

## 1. 채널 컨셉 잡기

- **누구에게(타겟)** · **무엇을(주제)** · **왜(차별점)** — 이 세 가지를 한 문장으로 정리할 수 있어야 함
- 예: "재테크 초보 20대에게, 실생활 지출 예시로, 어렵지 않게 설명하는 채널"
- 컨셉이 애매하면 알고리즘도, 시청자도 채널을 기억하지 못함

## 2. 콘텐츠 기둥(Content Pillar) 3~4개 정하기

채널 하나에 소재가 너무 흩어지면 구독 이유가 약해짐. 아래처럼 큰 카테고리를 미리 정해두기:

1. 정보성 (예: 꿀팁, 방법 설명)
2. 경험/후기 (예: 직접 해본 것, 실패담)
3. 트렌드/이슈 (예: 요즘 화제되는 것 다루기)
4. 시리즈물 (예: 매주 같은 포맷 반복)

## 3. 영상 포맷 정하기

- 롱폼(8분 이상) vs 숏폼(60초 이하) — 목적이 다름
  - 숏폼: 신규 유입, 노출 확대
  - 롱폼: 구독자 락인, 시청 지속시간 확보, 수익화(광고)에 유리
- 초반엔 숏폼으로 반응 테스트 → 반응 좋은 소재를 롱폼으로 확장하는 전략도 많이 씀

## 4. 후킹 구조 (특히 초반 3~5초가 핵심)

1. **훅(Hook)**: 왜 이 영상을 끝까지 봐야 하는지 3초 안에 제시
2. **문제 제기/공감**: 시청자가 겪는 문제나 궁금증
3. **본론**: 정보/경험/사례
4. **정리/요약**: 핵심만 다시 짚어주기
5. **CTA**: 구독/좋아요/댓글 유도 (자연스럽게)

## 5. 제목·썸네일 전략

- 제목: 궁금증을 유발하되 낚시성은 피하기 (신뢰도 하락 → 장기적으로 손해)
- 썸네일: 텍스트 최소화, 표정/색 대비로 시선 끌기, 폰트 크게
- 제목+썸네일은 "클릭률(CTR)"을 결정하는 가장 큰 요인

## 6. 업로드 주기

- 완벽한 퀄리티로 어쩌다 한 번보다, **일정한 주기**가 알고리즘/구독자 습관 형성에 더 유리
- 처음엔 무리하지 않는 주기(예: 주 1회)로 시작해서 지속 가능성 확보

## 7. 성과 확인할 지표

| 지표 | 의미 |
|---|---|
| 노출 클릭률(CTR) | 썸네일/제목이 매력적인지 |
| 평균 시청 지속시간 | 콘텐츠 본편이 만족스러운지 |
| 구독 전환율 | 채널 자체에 대한 관심도 |
| 트래픽 소스 | 유입 경로 (탐색, 추천, 검색 등) |
