# 틱톡 스마트 클립(Smart Split) 사용법

## 개요
틱톡 스튜디오(TikTok Studio)의 **스마트 클립** 기능은 긴 영상을 AI가 자동으로 분석해 여러 개의 짧은 숏폼 클립으로 잘라주는 도구. 자막(캡션) 자동 삽입, 9:16 세로 비율 자동 재구성도 지원.

## 설정 항목
- **변환할 부분 선택**: 타임라인에서 클립으로 만들 구간을 드래그로 지정
- **스마트 클립 동영상 길이 설정**: 자동 / 30초 미만 / 30~60초 / 60~90초 / 90초~3분
- **동영상 비율 선택**: 원본 그대로 vs AI로 9:16 세로 비율 재구성
- **캡션 프리셋 선택**: 자막 스타일 템플릿 (없음 선택도 가능)
- **처리 시간 할당량**: 월별 제한 있음 (예: 이번 달 50분 남음) — 선택한 구간 길이만큼 차감

## 30초 미만 클립 만드는 방법
1. 타임라인 바에서 원하는 구간 드래그로 선택
2. **스마트 클립 동영상 길이 설정**에서 "30초 미만" 클릭
3. (선택) 동영상 비율 — 원본 또는 9:16 AI 재구성 선택
4. (선택) 캡션 프리셋 선택 (자막 없으려면 맨 왼쪽 금지 아이콘)
5. 오른쪽 아래 검은색 **"스마트 클립"** 버튼 클릭 → 처리 시작

## 장단점 메모
- **장점**: 롱폼 영상 편집 시간 단축, 자막 자동 삽입으로 초기 세팅 부담 적음
- **단점**: AI가 고른 하이라이트 구간이 실제 "훅"과 항상 일치하진 않음 — 사람이 직접 편집한 것보다 반응이 떨어질 수 있음
- **추천 사용법**: 처음엔 1차 초안용으로 사용 후, 반응 좋을 것 같은 클립만 골라 직접 다듬는 방식이 효율적. 처리 할당량이 제한적이므로 짧은 구간으로 테스트 먼저 해보기
